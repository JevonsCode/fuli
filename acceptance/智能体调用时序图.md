# Fuli 智能体调用时序图

## 实现口径

当前实现不是由 Fuli 服务端无条件把所有知识推给模型，而是通过 MCP 指令要求智能体在每个
任务开始时先读取协作偏好。这样可以自动注入个人全局偏好和当前精确项目偏好，同时避免把
其他项目偏好带入当前对话。普通历史知识则由智能体根据任务内容决定是否检索。

```mermaid
sequenceDiagram
    autonumber
    actor U as 用户
    participant A as Codex 或 Claude Code
    participant P as Fuli 偏好入口
    participant K as Fuli 知识入口
    participant M as Fuli 项目管理入口
    participant G as Graphiti 图服务
    participant N as Neo4j 图数据库

    U->>A: 在项目甲中提交任务
    A->>P: 读取协作偏好（当前工作目录）
    P->>G: 识别当前个人空间和项目甲
    G->>N: 查询个人全局偏好和项目甲偏好
    N-->>G: 返回候选偏好与冲突
    G-->>P: 只保留有效偏好
    Note over P,A: 注入个人全局偏好与项目甲偏好<br/>不注入项目乙偏好<br/>不自动注入待确认偏好
    P-->>A: 返回有效偏好、当前项目和待处理冲突

    alt 当前任务可能依赖历史知识
        A->>K: 检索知识（包含待确认知识）
        K->>G: 构造有界检索作用域
        Note over K,G: 包含个人全局知识、项目甲、明确点名的上下文项目<br/>以及已订阅且与任务相关的公共项目
        G->>N: 查询本地知识与允许继承的上级知识
        Note over G,N: 只沿父子关系或知识复用关系向上查找<br/>最多两跳；普通关联关系不扩张范围
        N-->>G: 返回已确认、智能体已确认和待确认知识
        G->>G: 本地同稳定键知识覆盖继承知识
        G->>G: 按权威性、相关性和作用域距离排序
        G-->>K: 返回正文、确认状态、双分数和来源标记
        K-->>A: 提供模型可见的有界知识证据

        alt 知识实际影响回答、实现或决策
            A->>K: 记录一次引用或应用
            K->>G: 按知识、任务、使用类型和内容代次去重
            G->>N: 写入唯一有效使用事件
            G->>G: 更新效用分数和置信分数
            alt 达到五次且跨三个任务，并且没有未解决冲突
                G->>N: 晋级为智能体已确认
            else 未达到门槛或存在冲突
                G->>N: 保持原确认状态
            end
            K-->>A: 返回计数和晋级结果
        else 仅检索或查看
            Note over A,K: 不记录有效使用，不增加确认权重
        end
    else 当前任务不依赖历史知识
        Note over A,K: 不调用知识检索
    end

    opt 当前任务明确需要修改项目关系或项目资料
        A->>M: 预览项目写入（提交完整写入意图）
        M->>G: 验证项目、关系、冲突和目标
        G-->>M: 返回预览结果
        M-->>A: 返回短期、一次性预览令牌
        A->>M: 使用同一完整动作和预览令牌执行
        M->>M: 校验令牌匹配、有效且未使用
        M->>G: 执行项目写入
        G->>N: 保存变更
        M-->>A: 令牌失效并返回结果
    end

    A-->>U: 按有效偏好和支持性知识完成回答
    Note over A,U: 使用了 Fuli 证据时，回答开头和末尾保留来源标记
```

## 关键检查点

1. 偏好读取发生在任务开始阶段。
2. 项目甲不会自动携带项目乙偏好。
3. 待确认普通知识可以按需检索，待确认偏好不能自动注入。
4. 检索本身不增加有效使用次数。
5. 只有真正引用或应用后才记录使用。
6. 项目继承依赖明确关系、知识继承模式和两跳上限。
7. 最终回答只能引用模型实际看到的知识正文，不能只凭来源标题猜测。
8. 只读任务不得尝试调用项目写入工具；项目写入必须先预览并使用匹配的一次性令牌。
