# Fuli 知识与智能体验收

这个目录用于验证 Fuli 的知识检索、项目继承、偏好注入、确认状态和真实智能体调用流程。
验收连接真实的 Graphiti/Neo4j 图数据库服务，不使用内存假数据库代替最终结果。

- 产品或基础设施名称，例如 Codex、Claude Code、Graphiti、Neo4j。

## 运行确定性验收

```sh
npm run test:knowledge:live
```

脚本会复用一个与真实个人空间隔离的验收空间，并维护父项目、子项目、兄弟项目、孙级项目、
曾孙级项目和普通关联项目。所有模拟数据都通过公开接口创建，不直接写 Neo4j。

验收空间使用稳定标识和幂等键，可以重复运行。测试偏好不会进入用户当前个人空间。由于
目前没有个人空间删除接口，这个隔离空间会保留在本地 Provider 中，供后续回归复用。

脚本输出中文用例名称、中文通过状态、总耗时，以及 12 次有界项目检索的中位数、百分之
九十五分位数和最大耗时。性能数字只作为当前开发机的实时故障预算，不是跨机器性能承诺。

## 运行 MCP 返回边界验收

```sh
node --test test/mcp-integration.test.js
```

这个测试防止出现“图数据库已经命中，但智能体只能看到来源标题”的回归。模型可见结果必须
保留知识正文摘要、确认状态和判断分数，同时保持明确的 32 KiB 上限。

## 运行完整回归

知识验收通过后，再执行项目的 Node、Python、Web、构建和打包测试。提交前还应执行：

```sh
git diff --check
```

同时检查变更中没有真实凭据、个人标识、内部地址或机器专属路径。
