# Error codes

| Code | Meaning |
| --- | --- |
| TW-EMAIL-001 | Email recipient is not an address. |
| TW-EMAIL-002 | Email provider rejected the message. |
| TW-SMS-001 | SMS recipient is not an E.164 number. |
| TW-SMS-002 | SMS provider rejected the message. |
| TW-WEBHOOK-001 | Webhook target is not an http(s) URL. |
| TW-WEBHOOK-002 | Webhook endpoint rejected the message. |
| TW-RELAY-001 | The message names a channel that does not exist. |
| TW-PUSH-001 | Push message has no target device. |
| TW-PUSH-002 | Push provider rejected the message. |
