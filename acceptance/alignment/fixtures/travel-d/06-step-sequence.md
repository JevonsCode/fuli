# X → Y 连续步骤样本

> MOCK ACCEPTANCE FIXTURE / MOCK（合成）验收数据

以下三段是虚构的独立会话样本：

1. Agent 完成步骤 X：“生成变更说明草稿”；用户随后要求步骤 Y：“检查说明中的链接”。
2. Agent 完成步骤 X：“生成变更说明草稿”；用户随后要求步骤 Y：“检查说明中的链接”。
3. Agent 完成步骤 X：“生成变更说明草稿”；用户随后要求步骤 Y：“检查说明中的链接”。

稳定标记：步骤 X 为 `NETWORK-STEP-X-606`，步骤 Y 为 `NETWORK-STEP-Y-707`。

验收期望：Agent 可以形成“X 后通常建议 Y”的待确认候选，但不能仅凭三次样本自动执行 Y。下一次完成 X 时，应先询问用户是否执行 Y；只有用户明确同意“以后都这样做”，才允许建立长期自动化规则。
