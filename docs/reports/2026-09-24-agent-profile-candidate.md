# 0.8.1 Agent 个人主页与协作记忆验收

状态：0.8.1 发布候选已完成本地验证；发布与安装结果以 GitHub Release、npm 和本机版本为准。

## 变更

- 人员目录简化为姓名入口，链接到独立个人主页；高级配置保留独立入口。
- 展示角色风格、用户期望、任职、招聘、实际工作、合作伙伴和项目组织关系。
- HR 本地模糊搜索不额外调用模型；平台锁定策略与旧档案字段保留。
- 修复空间切换、迟到请求、深链接筛选、档案失败回退。
- 会话日志与模型上下文预算分开，默认闲置 7 天归档；归档复用已有摘要，不额外调用模型。
- 修复首次游标、超大日志前进、交接边界、分页恢复及重复提示词；不确定归属时阻断并明确提示。
- 明确项目 ID 可解决工作目录匹配歧义，仍校验作用域和任务上下文。
- 测试工具默认关闭，拆分重复定义并保留兼容入口。

## 范围与限制

Cursor 实际检查了对话、转录、生命周期、借调、验证门禁、记忆隔离、个人主页、
花名册、打包脚本、操作技能与相应测试；没有逐行检查仓库每个文件，也未代跑上述
测试。首次报告的旧版本完成资格经真实数据库验证为预期门禁，Cursor 已复核。
其 Ask 模式拒绝写入任务检查点，不能把检查点报告为已保存。

Hook 集成测试实际运行候选子进程和真实数据库，但 JSONL 使用合成宿主格式；
它不代表真实外部模型的一次完整宿主运行。Claude Code 的实际场景验证确认数据库
角色记忆接续，Chrome 另做页面交互；未验证生产交易或业务上线条件。

其他客户端目前保留任务关联与摘要；完整可见日志采集支持 Codex、Claude Code。
隐藏推理、附件二进制、未识别事件和明确省略记录不在原文覆盖范围。
合成个人档案不代表真实成长记录。已知问题关闭不等于软件绝对没有缺陷。
