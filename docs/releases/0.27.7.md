# FULI 0.27.7

0.27.7 发在 `latest` 渠道。这一版让你看得见 FULI 记住了你：新对话的第一条回复会说这次带上了你的几条习惯。另外，没用过的进阶功能先收起来，第一次接入客户端更顺。一个本地数据库会自动升级一次（见「数据格式」）。

0.27.7 is on the `latest` channel. This version lets you see that FULI remembered you: the first reply of a new conversation says how many of your habits it handed over. Advanced features you have not used are tucked away, and connecting clients for the first time is smoother. One local store upgrades itself once (see Data format).

## 更新内容 / What's new

FULI 一直在记你的习惯，可你怎么知道它记住了？以前只能信它。现在换个客户端、开个新对话，第一条回复的末尾会多一行：这次带上了你的 18 条习惯，点开看是哪几条。顺手把圆桌、整理这些你还没用到的东西先收了起来，省得一进门就眼花。

FULI has been keeping your habits all along, but how would you know? You had to take its word. Now open a new conversation in any client, and the first reply ends with one more line: this time it brought 18 of your habits, click to see which. And the things you have not used yet, the roundtable, tidying and the rest, are tucked away so the first look is not a wall of buttons.

## 新功能

- **看得见它记得你**：新对话的第一条回复末尾多一行「FULI 习惯：这个新对话带上了你的 N 条习惯」，点开是一张清单。说的是「带上」不是「用了」：FULI 亲眼看到的只有把习惯交给了助手，助手有没有照做，看它的回复。
- **进阶功能默认不露面**：圆桌和小组讨论、自动确认、整理、局域网配对，这台电脑用过或点开过才出现，出现后不再收起。还没用到的，在 设置 › 系统 › 还没用到的功能 里一键显示。升级上来的老用户，用过的入口都还在。

## 改进

- **第一次接入客户端**：接好后写明「新开的对话就能用；开着的要重启」；客户端开着导致接不上时说清原因，并可以直接「重启并接入」；一个都没找到时可以「再找一次」。
- **「说一条试试」的开头**改成「记住我的一个习惯：」。「我的习惯」「我习惯」这样的说法，FULI 也会当成让它记住。
- **被别的电脑唤醒的 Codex 只带 FULI 的工具**：你在 Codex 里接的其他服务和插件会被逐个关掉。配置读不出来时拒绝唤醒，不会退回到全部加载。

## 修复

- 在「完全信任」时已批准、还没开始就被你降了档的活，会退回给你拍板，不再照跑。
- 记录关着的时候让助手记住一条习惯，回执如实说「这条习惯没有记下：记录已关闭」，不再写成像是存了。

## In English

### New

- **See that it remembers you.** The first reply of a new conversation ends with "FULI 习惯：这个新对话带上了你的 N 条习惯", which opens a list. It says handed over, not applied: what FULI itself sees is that it gave the habits to the assistant; whether they were followed shows in the reply.
- **Advanced features stay out of sight.** The roundtable and group discussions, automatic confirmation, tidying and LAN pairing appear once this computer has used or opened them, and stay. What you have not used yet can be shown from Settings › System › Not used yet. Anyone upgrading keeps every entry they have used.

### Improved

- **Connecting clients for the first time.** A connected client says "new chats use it; restart it if it is open"; a client that is open says so and offers Restart and connect; with none found there is Look again.
- **The opener of "say one"** is now "Remember one of my habits: ". "My habit" is read as a request to keep it.
- **A Codex session woken by another computer carries FULI's tools only.** The other services and plugins you added to Codex are switched off one by one. When the configuration cannot be read the wake is refused instead of loading everything.

### Fixed

- Work approved under Full trust that had not started when you lowered that computer's mode goes back to you instead of running.
- Asking the assistant to remember a habit while recording is off now says plainly that it was not kept.

## 已知限制 / Known limits

- **只有你确认过的习惯会被带上。** 刚在客户端里说的一条习惯要先在「等你拍板」里确认，新对话才会带上它；新装的 FULI 要先选好在哪些项目里记录。所以一个全新的用户现在还看不到那一行。这两处正在改。
- 「带上了你的 N 条习惯」这一行在 Cursor 里不显示。
- 进阶功能默认不露面：升级后的样子在一台 Windows 上看过；全新安装的样子只有自动测试。
- Codex 只带 FULI 的工具：在 macOS 上用真实的 Codex 验过解析后的配置（只启用 FULI 一个）；被唤醒的会话里实际的工具清单还没有人亲眼确认，Windows 上没验。
- 两台真电脑之间还没有一件活完整跑完。这一版的其余改动在 macOS 上都没验证。

- **Only habits you confirmed are handed over.** A habit you have just stated in a client must first be confirmed under Waiting for you before a new conversation carries it, and a new installation first asks where to record. So a brand-new user does not see the new line yet. Both are being changed.
- The "带上了你的 N 条习惯" line does not show in Cursor.
- Advanced features out of sight: the upgraded look was seen on one Windows computer; a fresh installation is covered by automated tests only.
- Codex with FULI's tools only: the resolved configuration was checked with a real Codex on macOS (only FULI enabled); the tool list of a woken session has not been seen by anyone, and nothing was checked on Windows.
- No piece of work has run to the end between two real computers yet. The rest of this version was not checked on macOS.

## 数据格式 / Data format

召回记录库在第一次启动时自动升级（3 → 4，记下这次进入是不是开了一个新对话）。升级前会自动备份；升级后退回 0.27.6 需要用备份才能打开这个库。

The recall record upgrades itself on first start (3 → 4, whether an entry opened a new conversation). A backup is taken first; going back to 0.27.6 needs that backup to open it.
