# FULI 0.27.27

本版包含 0.29.0-beta.13 的全部功能。新项目可留在本机离线工作。配对电脑可按项目授权，双向搬移任务历史和 Jefa 看板。任务入口按需读取习惯，FLA 可以在另一客户端新开会话。

升级前请在每台电脑上创建整图备份。整图备份只能恢复到原机。图格式从 22 升至 25 时，请按控制台提示确认迁移。要退回 0.27.17、beta.10 或 beta.12，请先在「设置 › 系统 › 数据格式」撤销迁移，将图谱恢复到格式 22。如果无法撤销，请在原机恢复升级前的整图备份。回到这些版本后，配对电脑上原本由本机项目处理的调用会重新发往主机。

This release includes all features from 0.29.0-beta.13. Keep new projects on this computer and work offline. Paired computers can grant access by project and transfer task history and Jefa boards in either direction. Tasks load preferences on demand, and an FLA can open a chat in another client.

Back up each computer before upgrading. A full graph backup restores only to its original computer. Follow the console prompt when migrating from graph format 22 to 25. Before returning to 0.27.17, beta.10 or beta.12, undo the migration in Settings › System › Data format to return the graph to format 22. If FULI cannot undo it, restore the pre-upgrade full graph backup on the computer that created it. On those versions, paired computers send requests for local projects to the host again.

已安装 beta.13 的电脑已经使用相同的图格式和路由库。版本排序上 beta.13 高于 0.27.27，切换到这个正式版需要显式选择 0.27.27，保留现有图格式。

Computers running beta.13 already use the same graph and route formats. Since beta.13 sorts above 0.27.27, explicitly select 0.27.27 to switch to this stable release and retain the existing formats.
