# FULI 0.27.27

本版包含 0.29.0-beta.13 的全部功能。新项目可留在本机离线工作。配对电脑可按项目授权，双向搬移任务历史和 Jefa 看板。任务入口按需读取习惯，FLA 可以在另一客户端新开会话。

升级前请在每台电脑上创建整图备份。整图备份只能恢复到原机。图格式从 22 升至 25 时，请按控制台提示确认迁移。要退回 0.27.17、beta.10 或 beta.12，请先在「设置 › 系统 › 数据格式」撤销迁移，将图谱恢复到格式 22。如果无法撤销，请在原机恢复升级前的整图备份。回到这些版本后，配对电脑上原本由本机项目处理的调用会重新发往主机。

This release includes all features from 0.29.0-beta.13. Keep new projects on this computer and work offline. Paired computers can grant access by project and transfer task history and Jefa boards in either direction. Tasks load preferences on demand, and an FLA can open a chat in another client.

Back up each computer before upgrading. A full graph backup restores only to its original computer. Follow the console prompt when migrating from graph format 22 to 25. Before returning to 0.27.17, beta.10 or beta.12, undo the migration in Settings › System › Data format to return the graph to format 22. If FULI cannot undo it, restore the pre-upgrade full graph backup on the computer that created it. On those versions, paired computers send requests for local projects to the host again.

### 从 beta.13 切到正式版

两台配对电脑都显式选择 0.27.27。beta.13 的版本号更高，但两版使用相同的图和路由格式。先在每台原机备份，再停止 FULI 并退出桌面端。原生 Provider 首次启动需要明确同意降低版本号。

- **npm**　运行 `fuli stop`、`npm install --global fuli-context@0.27.27`，确认 `fuli --version` 为 `0.27.27`，再运行 `fuli start --allow-provider-downgrade`。
- **macOS 应用**　从 0.27.27 的磁盘映像替换已退出的 FULI.app。首次启动时，请 AI 或管理员在终端执行下方命令。应用安装在其他位置时调整路径。启动成功后可正常打开桌面端。
- **Windows 安装版**　从 0.27.27 的托盘 ZIP 解压到新目录，退出正在运行的托盘，再从新目录执行 `Update-Fuli.cmd --allow-downgrade`。更新程序会为首次启动传入 Provider 降版许可。

### Switching from beta.13 to stable

Choose 0.27.27 explicitly on both paired computers. Beta.13 has a higher version number, but both use the same graph and route formats. Back up each computer, stop FULI and quit the desktop client. The native Provider requires explicit consent for this version change on its first start.

- **npm** Run `fuli stop`, then `npm install --global fuli-context@0.27.27`. Confirm `fuli --version` prints `0.27.27`, then run `fuli start --allow-provider-downgrade`.
- **macOS app** Replace the closed FULI.app with the copy from the 0.27.27 disk image. For the first start, ask your agent or administrator to run the commands below. Adjust the path if the app is installed elsewhere. Open the desktop app after the start succeeds.
- **Windows installation** Extract the 0.27.27 tray ZIP into a new folder, quit the running tray, and run `Update-Fuli.cmd --allow-downgrade` from the new folder. The updater passes the Provider downgrade flag for the first start.

```sh
fuli_app="/Applications/FULI.app/Contents/Resources/fuli"
if [ "$("$fuli_app/runtime/node/bin/node" "$fuli_app/src/cli.js" --version)" = "0.27.27" ]; then
  "$fuli_app/runtime/node/bin/node" "$fuli_app/src/cli.js" start --allow-provider-downgrade
fi
```
