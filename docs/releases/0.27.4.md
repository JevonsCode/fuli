# FULI 0.27.4

0.27.4 发在 `latest` 渠道。这一版把「外派」补齐了：没装 FULI 的人可以凭一条链接只读地问你的一个项目；配对的电脑可以把一件活交给你这边的助手，在单独的副本里做，由你拍板。另外每发一条消息，FULI 的钩子快了大约半秒；更新失败时不会再把 FULI 弄得起不来。三个本地数据库会自动升级一次（见「数据格式」）。

0.27.4 is on the `latest` channel. It completes seconding: someone without FULI can ask one of your projects, read-only, through a link; a paired computer can hand a piece of work to your assistant, done in a separate copy and decided by you. And FULI's hook is about half a second faster on every message; a failed update no longer leaves FULI unable to start. Three local stores upgrade themselves once (see Data format).

## 更新内容 / What's new

以前别人想用你的项目知识，得先装 FULI、再配对。现在给他一条链接就行，只能看、会过期、随时撤销。配对的电脑还能把活「派」过来：你的助手在一份单独的副本里做，做完你看一眼，点「保留」或「丢弃」，它不会替你合并，更不会替你推送。顺便，每条消息前 FULI 那半秒的准备时间，基本没了。

Sharing your project knowledge used to mean: install FULI, then pair. Now a link is enough: read-only, it expires, and you can revoke it. A paired computer can also send work over: your assistant does it in a separate copy, you take a look and click Keep or Discard; it never merges for you, let alone pushes. And the half second FULI spent before every message is mostly gone.

## 新功能

- **访客链接**：在项目页生成一条链接，同一个网络里没装 FULI 的人，用自己的 AI 客户端就能只读地问这个项目。有效期 1、7、30 天，一键撤销；口令只显示一次。问过什么、被拒了几次都有记录。
- **活回你这边做**：配对电脑上的助手可以发来一件活。你的助手先出一份方案，你在「今天 › 等你拍板」里批准或拒绝；批准后在单独的副本和分支里做，做完你看摘要、文件和改动，点「保留分支」或「丢弃」。FULI 不合并、不推送。
- **四个档位**：每台配对的电脑可以设「只能问 / 计划 / 自动 / 完全信任」，默认「计划」。「自动」只放行小而安全的改动，由写死的规则判断；「完全信任」不用你批准，建议只给你自己的其他电脑用。
- **用了哪些客户端和模型**：账单「查看详情」底部列出这周各客户端和模型各干了多少，只记客户端真的报上来的，没报的写「模型未知」。Tonborg 选客户端和模型时也能拿到这份数字。

## 改进

- **每条消息快了约半秒**：钩子不再每次加载整个应用，只把事情转交给一直开着的 FULI。一台 Windows 上实测：Claude Code 约 748 → 182 毫秒，Codex 约 736 → 184 毫秒。FULI 没开时照旧，不会变慢。
- **被别的电脑唤醒的助手只带 FULI 的工具**：你自己在客户端里接的其他服务（比如 Notion）不会被带进去。
- **对方电脑版本太旧时会直说**：以前只给一个「消息无效」，现在提示请对方更新。
- 账单上按客户端分的次数旁边加了一句：它只数按客户端记下来的那部分，可能比上面的总数少。

- **讨论组里被唤醒的成员也只带 FULI 的工具**（FULI 认得出自己在那个客户端里的注册信息时）。

## 修复

- **更新失败后 FULI 两头都起不来**（一台 Mac 从 0.27.2 更新到 0.27.3 时遇到）：新版本还在启动就被判成失败，回滚又把应用包从它脚下换掉。现在：没确认新版本停下来就不动应用包；数据已经被新版本升级过就保留新版本再启动一次，不退回旧版本；图数据库不再依赖应用包所在的目录；提示里同时写第一次的原因和之后做了什么。Windows 的更新做了同样的修正。
- 钩子转发：连接在处理中途断开时，同一个事件不会再被跑两遍；同时进来的调用不会再超过上限。
- 访客链接：链接在请求途中被撤销或过期，不再返回结果；本机路径的尾巴不再漏给访客。
- 活回你这边做：进程还可能活着时不删副本，之后确认它没了再删；清理目录被换成别处的联接时拒绝清理。
- 档位：别的窗口改过之后，这个窗口回到前台会重新读取，不会再显示过期的档位。
- 「全部请求」页没有请求时，那张卡片不再撑满整页；读满 200 条时会写明只列出最近 200 条。

## In English

### New

- **Guest links.** Create a link on a project's page; someone on the same network without FULI can ask that project, read-only, from their own AI client. It lasts 1, 7 or 30 days and is revoked in one click; the token is shown once. What was asked and how often it was refused is recorded.
- **Work done on your side.** An assistant on a paired computer can send a piece of work. Your assistant plans it first, and you approve or decline under Today › Waiting for you; once approved it is done in a separate copy and branch, and you read the summary, files and changes and click Keep branch or Discard. FULI never merges or pushes.
- **Four modes.** Each paired computer is set to Ask only / Plan / Auto / Full trust; Plan is the default. Auto lets through only small, safe changes, judged by fixed rules; Full trust needs no approval and is meant for your own other computers.
- **Which clients and models were used.** The statement's details list what each client and model did this week: only what a client reported, "model unknown" otherwise. Tonborg gets the same numbers when it picks a client and model.

### Improved

- **About half a second faster per message.** The hook no longer loads the whole application each time; it hands the event to the FULI that is already running. Measured on one Windows computer: Claude Code about 748 → 182 ms, Codex about 736 → 184 ms. With FULI closed it works as before, no slower.
- **An assistant woken by another computer carries FULI's tools only.** Other services you added to that client (Notion, for example) are left out.
- **An older version on the other computer is named as such.** It used to answer "invalid message"; it now says to update the other computer.
- The per-client counts on the statement say that they cover only what was recorded per client, so they can be lower than the totals above.

- **A member woken for a group discussion carries FULI's tools only too**, where FULI can name its own entry in that client.

### Fixed

- **A failed update could leave FULI unable to start at all** (met on a Mac updating 0.27.2 to 0.27.3): the new version was judged failed while still starting, and the rollback swapped the app from under it. Now nothing is moved unless the new version stopped; data the new version already upgraded keeps the new version, started once more, instead of going back; the graph database no longer depends on the app's own folder; the message gives the first reason and what was done after it. The Windows update got the same corrections.
- Hook forwarding: an event no longer runs twice when the connection drops mid-way, and calls arriving together no longer exceed the cap.
- Guest links: a link revoked or expired during a request returns nothing; the tail of a local path no longer reaches a visitor.
- Work done on your side: a copy is not removed while its process may still be alive, and is removed once it is gone; cleanup is refused when its folder was replaced by a link to somewhere else.
- Modes: a window that comes back to the front reads the modes again, so it no longer shows one another window changed.
- With no requests, the card on the All requests page no longer stretches to the full page height; a read cut at 200 says that only the newest 200 are listed.

## 已知限制 / Known limits

- 「活回你这边做」目前只用 Claude Code 来执行，不用 Codex。电脑上 Claude Code 命令行不能用、或共享里只勾了 Codex 时，对方发来的活会被拒绝并说明原因。
- 它依赖的三点（读写关在工作目录里、写不进设置和 git 文件、没有子代理工具和 MCP）已在 Windows 上用真实的 Claude Code 2.1.301 验过，并在合成仓库上跑通了六件活；macOS 上还没验，也还没有在两台真电脑之间发过请求。
- 访客链接在网络上是明文传输的，能看到这个网络流量的人就能看到口令；所以只在同一个网络里能用，并且有效期短、可随时撤销。还没有从另一台电脑试过。
- **Mac 上从 0.27.3 升到这一版，建议下载 dmg 覆盖安装，不要用应用内的一键更新**：一键更新由旧版本（0.27.3）自带的更新程序执行，这一版对更新流程的修复要到下一次更新才起作用。Windows 不受影响。
- 更新流程的修复在 Windows 上实际走过一次成功的更新；失败和回滚的几种情况只在自动测试里验过，macOS 上还没有在真实更新里验证。
- 钩子提速在 macOS 上还没量过；更新之后要等 FULI 服务重启才生效。
- Claude Code、Cursor、OpenCode 的任务入口拿不到模型名，所以显示「模型未知」。

- Work done on your side is run by Claude Code only, not Codex. Where the Claude Code CLI cannot run, or a share allows only Codex, a request is refused with its reason.
- The three things it rests on (reads and writes confined to the working folder, no writes to settings or Git files, no subagent tool and no MCP server) were checked on Windows with the real Claude Code 2.1.301, and six requests ran end to end on a synthetic repository; not yet on macOS, and no request has travelled between two real computers.
- A guest link travels unencrypted on the network: whoever can see that traffic can see the token. So it works on the same network only, lasts a short time and can be revoked. It has not been tried from another computer yet.
- **On a Mac, go from 0.27.3 to this version by installing the dmg over the app, not with the in-app update**: the in-app update is run by the old version's (0.27.3) own updater, so this version's fixes to the update apply from the next update on. Windows is not affected.
- The update fixes went through one real, successful update on Windows; the failure and rollback cases were checked by automated tests only, and nothing was checked in a real update on macOS.
- The hook speed-up has not been measured on macOS; after updating it applies once the FULI service has restarted.
- The task entries of Claude Code, Cursor and OpenCode cannot learn the model name, so it reads "model unknown".

## 数据格式 / Data format

没有新增图谱迁移步骤。三个本地数据库在第一次启动时自动升级：召回记录库（2 → 3，记下入口报告的模型）、圆桌库（10 → 11，记下每次唤醒的模型和 token）、来访记录库（到 4，多了访客链接和来访请求的表）。升级前会自动备份；升级后退回 0.27.3 需要用备份才能打开这些库。

No new graph migration step. Three local stores upgrade themselves on first start: the recall record (2 → 3, the model an entry reported), the roundtable store (10 → 11, the model and tokens of each wake) and the visitor record (to 4, tables for guest links and visit requests). A backup is taken first; going back to 0.27.3 needs that backup to open them.
