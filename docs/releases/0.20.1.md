# FULI 0.20.1

0.20.1 是 0.20.0 的补丁版，只修复一处隐私问题，没有数据格式变化，不需要迁移（JevonsCode/rec#50）。

## Agent 读取 Tonborg 审核记录时，按条目现在的可见性返回

0.20.0 里，Tonborg 审核记录存在本机的 judgment 记录里。条目审核之后如果改成某个 Agent（FLA）私有，其他 Agent 或普通会话仍然能从这些旧记录里读到它审核时的标题、摘要和 target。审核摘要还可能夹带 Tonborg 当时读到的偏好、记忆和此前的反馈。

0.20.1 起：

- **Agent 能读到的审核和判断记录只含结构化字段**：编号、类型、结论、置信度、拦截原因、时间、模型等。摘要、理由、证据、问题原文这类自由文本一律不返回，被扣下的字段列在 `content_withheld` 里。
- **条目的 target 和标题只在读者现在能看到这个条目时才返回**。看不到、已删除、无法确认（包括 Provider 不可用）时都不返回，并标 `target_withheld`。
- 这些规则适用于所有 Agent 能走到的出口：`list_judgments`、`review_with_tonborg`（含重放和缓存）、`assess_agent_action`、`assess_task_completion`、checkpoint 问题投递，以及 role_work 的提交、重试和缓存重放。
- **当前会话代答 Tonborg（没有配置模型时）**：会话拿到的工作包只有候选本身、它自己的证据、审核规则，以及这个会话现在能看到、而且和原先记录一字不差的偏好。Tonborg 的记忆、此前的决定和反馈不再给出。候选对这个会话不可见时，拒绝代答。偏好有被扣下、新出现、范围变化，或者当前读到的不如原先完整时，回执标 `partial` 和 `context_changed`，让会话按规则升级给本人。
- **本人在控制台**（带本机 human-review 证明）仍然能看到完整历史。Tonborg 自己的本机模型仍然使用完整上下文。
- 问本人的审核问题不再引用模型写的摘要，只写结论和（读者可见时的）条目标题，并提示到控制台查看理由。

**已知限制**：Agent 的身份由调用方自报，和搜索、0.20 其他读取路径的信任模型相同。控制台证明只说明请求来自本机控制台，不证明是本人在场。

In English: 0.20.1 is a privacy patch with no data format change. Agent-facing reads of Tonborg's judgment records now return only structured fields (free text such as summaries and evidence is withheld), and an item's target and title only while the reader can still see that item; anything that cannot be confirmed is withheld. A session answering for Tonborg gets a minimal package (the candidate, its own evidence, the criteria and the rules it can still read unchanged) and is refused a candidate it cannot see. The console, with the local human-review proof, keeps the full history.

## 安装和升级

需要 Node.js >= 24.12。

```sh
fuli stop
npm install --global fuli-context@latest
fuli setup --yes --connected-only
fuli --version
```

从 0.20.0 升级不需要额外步骤。从更早的版本升级，请先看 `docs/releases/0.20.0.md`。
