# FULI 0.27.0

0.27.0 发在 `latest` 渠道。它比名字看起来大：新接了一个客户端、搜索不用再接模型、设置重新归了类，也删掉了一整块没人用的功能。图谱数据不需要迁移；本地多了两个小文件（见「数据格式」）。公共项目相关的功能和工具已移除（见「移除」）。
0.27.0 is on the `latest` channel. It is bigger than its number: one more client, search by meaning without a model service, settings regrouped, and a whole unused feature removed. The graph needs no migration; two small local files are new (see Data format). Public projects and their tools are gone (see Removed).

## 更新内容 / What's new

这次不用你接模型了：点一下，FULI 自己下一个小模型在本机跑，换个说法也搜得到。项目页多了「整理」，挑一个你的 AI，让它把项目读一遍、补上 FULI 还缺的。设置里同一件事不再分三个地方放。第一次打开会有个六步的新手引导，嫌烦可以跳过。

No model service needed this time: one click and FULI downloads a small model that runs on your computer, so a question asked another way still finds its answer. A project page has 整理: pick one of your AI clients and it reads the project and fills in what FULI is missing. Settings keeps each subject in one place. A six-step guide greets the first open; skip it if you like.

## 新功能

- **按意思搜索，不用接模型**：在「模型与用量 › 语义搜索」点「内置模型」，FULI 下载一个小模型（推荐 GTE Small 中文）在这台电脑上运行，不需要接口地址和密钥，知识不出本机。待确认的知识也能按意思找到。想用自己的模型服务，照旧可以改接。
- **整理一个项目**：项目概览页点「整理」，选一个已接入的 AI 客户端，它用自己的模型读项目文件和历史，补上缺的、合并重复的、标出过时的，并把拿不准的列成一张「是 / 否 / 其他」的短单子。可以告诉它已有资料在哪（文件夹、文件、链接）。某条偏好在几个项目里都有时，会问你要不要升成全局。
- **接入 DeepSeek Harness**：在「设置 › 客户端」一键接入，FULI 的插件和三个 Skill 会装进 DSH。别人的同名依赖和链接不会被动。
- **新手引导**：这一版第一次打开时出现一次，六步讲清怎么用；可以跳过，「设置 › 系统 › 界面」里能再看一遍。
- **圆桌**：找一位 FLA 时按三步来：接上它上次的会话，不行就新开，再不行由当前会话代入并标明。用了圆桌的那一轮，回执会写出参与的 FLA 并附上对话链接。
- **检查点可以更正**：发早了的工作记录能补一条更正，原记录保留。
- **话题长成项目时**：Bole 给它配一个小组，并把手头的事交接给每个人。

## 改进

- **设置重新归类**：五个标签——记录、AI 能做什么、客户端、连接、系统。原来的「连接」页并进了设置，旧地址会自动跳到新位置。
- **页面目录**：右边缘的小短线换成了一个小胶囊，一眼看得出在第几节；鼠标移上去展开节名。
- **模型页**：每个用途一张小卡片，出错时每一种都写了下一步怎么办。
- **搜索排序**：完全对得上的排在只对上一部分的前面，即使它还没确认；只撞上项目里常见词的不算命中。
- **Tonborg 的提问**：改成直白的是 / 否 / 其他，一批只提醒一次。
- **官网和 README**：新手引导的句子重写过，读起来像人写的。

## 修复

- **版本冲突时说人话**：这台电脑的数据由更新的 FULI 保存过时，桌面端会用当前语言说明两个版本号、数据没有改动、更新后再启动，不再甩出一段英文报错。
- **控制台没起来时自己拉起**：图服务在跑而控制台进程不在时，客户端会自己启动控制台；控制台只是应答慢时不会被重启。
- **模型存不下时不怪网络**：磁盘满或文件夹不可写时，提示说的是磁盘，不是「可能连不上」。
- **Claude Desktop 把旧配置写回去时**会说明，并给「重启并更新」。
- **工作台**里出现的每位 FLA 都有名字；圆桌标题栏的按钮显示文字；Codex 提问卡片里选的答案能转达。
- **安全**：Agent 工具不能指定连接器的命令或凭据；只有带人工复核证明的修改才会被记成「本人修改」。

## 移除

- **公共项目**：公共项目页、发布、订阅、项目关系、两个评审队列和「公共知识晋升」连同 15 个 Agent 工具一起移除。旧客户端调用这些工具会得到「已退役」的回答，保留一个版本。采集只进个人空间。已有数据照常可读，彻底删除知识时仍会清理旧的发布草稿。
- **`/flreview` 知识回顾**下线，整理和 Tonborg 的确认接替了它。
- 另外清掉了六个早已不用的旧功能和一批没有调用方的代码。

## In English

**New**
- **Search by meaning without a model service.** In Models › Semantic search, click 内置模型: FULI downloads a small model (GTE Small 中文 is recommended) and runs it on this computer. No endpoint, no key, nothing leaves the computer. Pending knowledge is found by meaning too. Your own model service still works.
- **Organise a project (整理).** On a project's overview, pick a connected AI client; with its own model it reads the project's files and history, fills in what is missing, merges what repeats, marks what is stale, and leaves a short yes / no / other list for what it could not settle. You can say where existing material is. A preference several projects share is offered as a global one.
- **DeepSeek Harness** connects with one click in Settings › Clients; FULI's plugin and three Skills go into DSH. Someone else's dependency or link of the same name is left alone.
- **A beginner's guide** shows once on the first open of this version: six steps, skippable, and available again in Settings › System.
- **Roundtable.** An FLA is brought in by a three-step ladder: resume its last session, else open a new one, else the current session stands in, labelled. A turn that used the roundtable signs with who took part and links the conversation.
- **A checkpoint sent too early can be amended**; the original is kept.
- **A topic that grows into a project** gets a team from Bole and a handover to each member.

**Improved**
- **Settings in five tabs**: Recording, What AI may do, Clients, Connections, System. The Connections page moved into Settings; old addresses redirect.
- **Page outline**: a small capsule with a dot per section replaces the grey dashes; hover opens the names.
- **Models page**: one compact card per use, and a way forward from every failure.
- **Search ranking**: an exact match ranks above a partial one even while pending; sharing only a project's common words is not a match.
- **Tonborg's questions** are plain yes / no / other, with one reminder per batch.
- **Website and README**: the guide's sentences were rewritten in plain words.

**Fixed**
- **A version conflict is explained**: when a newer FULI saved the data on this computer, the desktop client says so in your language, with both versions, that nothing was changed, and to update.
- **The console starts by itself** when the graph service runs without it; a console that is only slow is not restarted.
- **A model the disk refused is not blamed on the network.**
- **Claude Desktop writing its old FULI entry back** is said, with 重启并更新.
- Every FLA on the workbench has its name; the roundtable title bar's button shows its words; a choice picked in Codex's question card is relayed.
- **Security**: Agent tools cannot name a connector's command or credential; a change is recorded as the person's own only with the human-review proof.

**Removed**
- **Public projects**: the page, publishing, subscriptions, project relations, both review queues and common-knowledge promotion, with 15 Agent tools. An older client that calls one is told it was retired, for one release. Capture goes to the personal space only. Existing data stays readable; permanent deletion still cleans up old publication drafts.
- **The `/flreview` knowledge review** is retired; organising and Tonborg's confirmation replace it.
- Six long-unused features and code without a caller were removed.

## 数据格式 / Data format

图谱没有新的迁移步骤，升级不需要确认。本地新增两个文件：`embedding-models.json`（内置模型目录的状态）和 `project-organizing.json`（每个项目整理到哪了，不含知识）。退回 0.25.2 时这两个文件会被忽略。已有的内置模型在升级后会按新的命名重建一次索引，自动完成。

The graph has no new migration step, so upgrading asks for nothing. Two local files are new: `embedding-models.json` (the state of the built-in model catalog) and `project-organizing.json` (how far each project has been organised; it holds no knowledge). Going back to 0.25.2 ignores both. A built-in model already in use rebuilds its index once after the upgrade, by itself.

## 安装和升级

需要 Node.js >= 24.12（桌面客户端已内置）。

- **Windows**：在控制台「设置 › 系统 › 版本与更新」点「更新到 v0.27.0」一键更新。也可以下载 `FULI-Setup-0.27.0.exe` 双击（先核对同名 `.sha256`），已装过的会直接更新，数据保留。还可以下载 `fuli-windows-tray-0.27.0.zip`（同样核对 `.sha256`），解压后运行 `Update-Fuli.cmd`。
- **macOS（FULI.app，Apple 芯片）**：在「设置 › 系统 › 版本与更新」点「更新到 v0.27.0」一键更新。第一次安装：下载 `fuli-macos-arm64-0.27.0.dmg`（核对同名 `.sha256`），把 FULI 拖进「应用程序」再打开。
- **npm**（虚拟机、云和服务器）：

```sh
fuli stop
npm install --global fuli-context@latest
fuli setup --yes --connected-only
fuli --version
```

升级后重启一下已接入的 AI 客户端，让它们用上新版的 MCP 和 Hook。

Requires Node.js >= 24.12 (built into the desktop client).

- **Windows**: click 更新到 v0.27.0 in Settings › System › Version and updates. You can also double-click `FULI-Setup-0.27.0.exe` (check its `.sha256` first), which updates an existing install and keeps your data. Or unzip `fuli-windows-tray-0.27.0.zip` (check its `.sha256`) and run `Update-Fuli.cmd`.
- **macOS (Apple silicon)**: click 更新到 v0.27.0 in Settings › System › Version and updates. For a first install, download `fuli-macos-arm64-0.27.0.dmg` (check its `.sha256`) and drag FULI to Applications.
- **npm** (VMs, cloud, servers): run the commands above.

After upgrading, restart your connected AI clients so they load the new MCP server and hooks.
