# Fuli 0.9.0

- Replies identify the FULI Agent responsible for the current task and link to its profile.
- Refreshed Agent cards, project work summaries, profile navigation, settings and loading states.
- Improved task-context compatibility with older Providers and native runtime upgrades.
- Roundtable workers follow their assigned roles and execution scope more consistently.

## Upgrade

```sh
npm install -g fuli-context@0.9.0
fuli setup --yes
```
