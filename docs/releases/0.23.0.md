# FULI 0.23.0（草稿 / draft）

草稿：发版时与其他改动合并整理。 / Draft: merged with the other changes at release time.

- Windows 安装包的托盘程序换成 FULI 桌面客户端：一个窗口显示 FULI 是否正常、能修什么，托盘图标是 FULI 标志加绿色、琥珀色或红色圆点。桌面和开始菜单的 Fuli 快捷方式打开它；旧的 FuliTray 托盘不再提供。
- 每个 Windows 用户只运行一个客户端，再次打开会显示已有窗口。安装后的客户端默认开机启动（只显示托盘图标），可在托盘菜单「开机时启动」关闭。
- Update-Fuli、Rollback-Fuli 和控制台的一键更新会先关闭正在运行的客户端，完成后重新打开它；Uninstall-Fuli 会关闭客户端，并删除开机启动项。客户端正在启动、停止或换端口时，会先做完再关闭。
- 托盘菜单保留「换一个端口」；因 Windows 保留端口而启动失败时，客户端会提示使用它。
- 从旧版托盘一键更新到这个版本时，旧托盘会退出，更新后打开的是新的桌面客户端。

- The Windows package's tray app is now the FULI desktop client: one window that shows whether FULI works and what it can fix, and a tray icon with the FULI logo and a green, amber or red dot. The Fuli shortcuts on the Desktop and Start menu open it; the old FuliTray tray is no longer shipped.
- One client runs per Windows user; opening it again shows the running window. An installed client launches at login by default (tray icon only); turn it off with Launch at login in the tray menu.
- Update-Fuli, Rollback-Fuli and the console's one-click update close a running client first and open it again afterwards; Uninstall-Fuli closes it and removes the launch-at-login entry. A start, stop or port change in progress finishes before the client closes.
- The tray menu keeps Use another port; when a start fails because Windows reserves the port, the client says to use it.
- A one-click update from an older tray to this version closes the old tray and opens the new desktop client afterwards.
