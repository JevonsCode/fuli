# FULI 0.25.1

0.25.1 是 0.25.0 的修复版，发在 `latest` 渠道。没有数据格式变化，升级和退回 0.25.0 都不用迁移。
0.25.1 is a fix release for 0.25.0 on the `latest` channel. No data format changes, so you can upgrade, or go back to 0.25.0, with no migration.

## 更新内容 / What's new

一个小修版：FLA 之间喊人更靠谱了，喊不醒的不会再一直占着位子。图谱服务打个盹时，任务照常开始，记录也能原样补存。Claude 桌面版的 Code 标签页里，圆桌回复和记录不再报错。

A small fix release: FLAs reach each other, and a stuck wake no longer blocks one forever. When the graph service naps, tasks still start and a checkpoint can be finished by sending it again. In Claude Desktop's Code tab, roundtable replies and checkpoints work again.

## 修复

- **圆桌唤醒不再一直卡着（rec#97）**：控制台在唤醒途中重启或崩溃后，这个 FLA 唯一的唤醒位会一直被占，之后发给它的圆桌消息和即时对话都不会叫醒它。现在一个小时内没人结束的唤醒会自动作废，卡住的消息回到收件箱，可以再读或撤回；进程没确认退出的照旧保留安全占位。被占时的提示也写明了什么时候放开。
- **图谱服务没响应时，任务照常开始（rec#105）**：`get_collaboration_preferences` 不再报错，改为返回 `preferences_unavailable`，并告诉 AI 接着干活、不编偏好、稍后再试。
- **checkpoint 超时能原样补完（rec#39）**：图谱服务没响应时，`checkpoint_task_knowledge` 返回 `checkpoint_incomplete`，提示用完全相同的参数重试；换了措辞被拒时也会这么提示。
- **Codex 回合中途插话不再让 Hook 报错（rec#85）**：回合进行中收到的回复或插话沿用这一轮的场景，不再被当成改了任务范围而拒绝。Hook 失败时，诊断里会记下是哪条规则拒的。
- **Claude 桌面版的 Code 标签页（rec#107）**：Code 标签页的 Hook 发的 token，在 Claude 桌面版的 FULI 连接里也能用了，圆桌回复和 checkpoint 不再全部失败。

## In English

- **Roundtable wakes no longer stay stuck (rec#97).** If the console restarted or crashed mid-wake, the FLA's single wake stayed claimed, and no later roundtable message or chat could wake it. Now a wake that nothing ends within an hour expires, and its message returns to the inbox, where it can be read or cancelled. A run whose exit is unconfirmed keeps its safety hold. The refusal now says when the hold ends.
- **Tasks start when the graph service does not answer (rec#105).** `get_collaboration_preferences` returns `preferences_unavailable` with guidance instead of an error.
- **A timed-out checkpoint can be finished (rec#39).** `checkpoint_task_knowledge` returns `checkpoint_incomplete` and asks for the same input again. A reworded retry that is refused says the same.
- **Codex input that arrives mid-turn no longer fails the hook (rec#85).** It keeps the turn's scene. A hook failure now records which rule refused it.
- **Claude Desktop's Code tab (rec#107).** Its hook tokens now work on Claude Desktop's FULI connection, so roundtable replies and checkpoints work again.

## 数据格式 / Data format

没有变化。0.25.0 和 0.25.1 读写同样的数据，可以随时互相切换。
No change. 0.25.0 and 0.25.1 read and write the same data, so you can switch either way at any time.

## 安装和升级

需要 Node.js >= 24.12（桌面客户端已内置）。

- **Windows**：在控制台「设置 › 版本」点「更新到 v0.25.1」一键更新。也可以下载 `FULI-Setup-0.25.1.exe` 双击（先核对同名 `.sha256`），已装过的会直接更新，数据保留。还可以下载 `fuli-windows-tray-0.25.1.zip`（同样核对 `.sha256`），解压后运行 `Update-Fuli.cmd`。
- **macOS（FULI.app，Apple 芯片）**：在「设置 › 版本」点「更新到 v0.25.1」一键更新。第一次安装：下载 `fuli-macos-arm64-0.25.1.dmg`（核对同名 `.sha256`），把 FULI 拖进「应用程序」再打开。
- **npm**（虚拟机、云和服务器）：

```sh
fuli stop
npm install --global fuli-context@latest
fuli setup --yes --connected-only
fuli --version
```

升级后重启一下已接入的 AI 客户端，让它们用上新版的 MCP 和 Hook。

Requires Node.js >= 24.12 (built into the desktop client).

- **Windows**: click 更新到 v0.25.1 in Settings › Version. You can also double-click `FULI-Setup-0.25.1.exe` (check its `.sha256` first), which updates an existing install and keeps your data. Or unzip `fuli-windows-tray-0.25.1.zip` (check its `.sha256`) and run `Update-Fuli.cmd`.
- **macOS (Apple silicon)**: click 更新到 v0.25.1 in Settings › Version. For a first install, download `fuli-macos-arm64-0.25.1.dmg` (check its `.sha256`) and drag FULI to Applications.
- **npm** (VMs, cloud, servers): run the commands above.

After upgrading, restart your connected AI clients so they load the new MCP server and hooks.
