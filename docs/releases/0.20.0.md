# FULI 0.20.0（草稿；0.20.0-rc.3 预览版用于本机验收）

- 会话不再自动建项目、自动招人：没有归属的会话交给固定助理接待，Jefa 在收尾时分诊，同一话题累计 3 个会话自动成为正式项目。
- 项目必须有简介；Agent 必须有职业，Bole 按职业招聘，组长只负责拆活、派活和收口。
- 新增项目间取记忆权重（有关系 / 常往来 / 密切），项目关系图和项目页可直接看到；权重不授予权限。
- 圆桌可以按项目找到对方组长，完成限定请求后把结果交回原组长。
- 任务入口大幅缩小（约 −66%），共享规则改为按需读取；新增 Token 门禁，入口或工具说明变大会被测试拦下。
- Windows 已安装版本可以用 Update-Fuli 预览并升级，保留数据和旧版本，失败自动回退。
- 新控制台外壳：六个入口（星图、Agents、对话、项目、记忆、设置），侧边栏可展开，窄屏用底部 Tab；统一的按钮、下拉、开关等共享组件。
- 按住 Alt（Mac 上是 Option）或点顶栏的 ⓘ，再点任意状态或名词，就能看到解释。
- 知识和偏好显示权重百分比（待确认 10–69%、Agent 确认 70–95%、你确认 100%），不再用二元的确认状态。
- 日常审核交给 Tonborg；真正需要你判断的，在会话里用宿主原生的选择题问你。
- Agent 举手等你决定时，可以通知本机的 DingDong（设置 → 通知）。
- 圆桌新增 Agent 私聊、群组和互相发现（包括跨电脑），只管通信、不计权重。
- 项目列表默认隐藏临时项目，一键可以显示。
- 内置助理改名 Astro，有了自己的头像。
- 更省 Token：默认工具说明缩小约 25%，每个任务的入口减半；Hook 已经下发上下文、又没有内容可记的任务，由 Stop Hook 自动收尾，省掉一次模型往返。
- 更省 Token（rc.3）：Codex 默认用精简的 chat 工具档（工具说明 30 KB → 7.8 KB），少用的工具通过 fuli_call 按需调用；采集 Skill 从 33 KB 拆成 7 KB 核心加按需读取的参考；自动带上的旧上下文最多 4 KB，搜索结果按 8 KB 分页、可以继续读完；升级后还在运行的旧 MCP 进程会提示重启客户端。Codex 拿到的说明只提默认已列出的工具，不再每个任务先多花一次模型往返去找工具。
- 记忆的四个页面（知识、偏好、写作品味、知识整理）用同一套布局；偏好详情就地展开。
- 对话：圆桌和问过你用同一种左右布局；圆桌能看到 Agent 之间的私聊和群聊，座位圆环换成成员标签。
- 职业目录：内置更多职业，自定义职业必须写清楚要做的事，点职业就能看到职责；四个内置角色的职业不能改。
- Agents 页：筛选行可以按最近工作或名字排序，搜索收成一个图标；团队管理只保留一个「编排」入口。
- 不再有「待审核」页：日常审核交给 Tonborg，发布到公开项目的决定放在「公开项目 → 待发布」，有内容时才出现。
- 设置可以搜索；AI 客户端能解释每个设置的作用和影响，并给出直接打开该设置的链接（设备设置仍由你来改）。
- 工作台有四种设计可在设计实验室里切换，其中「星图」把项目画成星球、Agent 绕着转，等你的会闪、在干活的会呼吸；设计实验室还能试配色、卡片、密度、圆角和运行光环。
- 设置 → 客户端接入能发现本机已装的 Agent 客户端（新增 Gemini CLI、OpenCode、Qwen Code、Kiro），点一下就接入，接入后重启客户端即可。
