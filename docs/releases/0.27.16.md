# FULI 0.27.16

0.27.16 发在 `latest` 渠道。托盘能看到每位助手在哪个项目、干什么；新来的 FLA 会自我介绍；添加客户端会自己验收。没有需要你确认的数据升级。

0.27.16 is on the `latest` channel. The tray shows each assistant's project and task; a new FLA introduces itself; adding a client checks that it really reaches FULI. No data upgrade to confirm.

## 更新内容 / What's new

这一版都是 11-17 晚上用 FULI 时遇到、当晚改好的：新电脑上第一次打开，「今天」页有一根又高又窄的黑按钮；托盘只写名字，看不出谁在干什么；公司的客户端接上了，却没走 FULI。

Everything here was met while using FULI on the evening of 11-17 and fixed that night: a new computer's first 「今天」 showed a tall, thin black button; the tray named assistants without saying what they do; a company client connected but never went through FULI.

## 改了什么

- **托盘每一行写清在干什么**：「名字 · 项目：在做的事」。任务关联了看板时写看板任务，助手收尾后写它的小结；FULI 不保存你发的原话，所以进行中的任务大多只写「名字 · 项目」。
- **新 FLA 会自我介绍**：一位 FLA 第一次替你干活，或者一个项目的负责人交接给它时，在「FULI Agent：…」下面说一句，告诉你它管什么、怎么找它（消息开头写 `#FLA 名字`）。每种情况只说一次；升级前就有的 FLA 不会突然说「初次见面」。
- **添加客户端会自己验收**：用提示词添加客户端，最后一步会让它调一次 FULI 的任务入口，回复末尾必须出现「FULI Agent：…」，否则会告诉你。只看到工具列表不算接好。
- **新装时的「今天」页**：「说一条试试」恢复成正常大小的按钮，和那句话一起居中。
- **「资源占用」刷新不再闪**：刷新时数字留在原处，只有你点「刷新」时按钮自己转圈。

## In English

### New

- **Each tray row says what the assistant is doing**: "name · project: task". The task is the linked board task's title, or the assistant's summary once it wraps up; FULI keeps no prompt text, so a task under way usually reads "name · project".
- **A new FLA introduces itself**: the first time an FLA works for you, or a project's lead passes to it, one line under 「FULI Agent：…」 says what it looks after and how to reach it (start a message with `#FLA name`). Once per occasion; FLAs you had before the update do not suddenly say hello.
- **Adding a client checks itself**: the add prompt's last step has the client call FULI's task entry and end its reply with the 「FULI Agent：…」 line, and tell you if it cannot. Tools showing up is not enough.

### Fixed

- **A new installation's 「今天」**: 说一条试试 is a normal-size button again, centred with its sentence.
- **资源占用 no longer flickers on refresh**: the numbers stay in place; only 刷新 turns its own button while it reads.

## 已知限制 / Known limits

- 托盘菜单不能放头像：系统菜单在 Windows 和 Mac 上都只显示文字。
- 手动添加的客户端仍然只装了 MCP，还没有 FULI 的全局说明，任务入口靠模型自己照做；新的验收一步能及时发现没走到的情况。
- 全新安装时，内置的 FLA 第一次替你干活会自我介绍；升级的用户里，已有的 FLA 只在项目交接时才说话。
- **Mac 上每次更新 FULI 后，系统已存的文件夹许可就对不上新版本了**；根上的原因是 Mac 版还没有稳定的签名身份。
- 其余限制同 0.27.15。

- The tray menu cannot show avatars: the system menus on Windows and the Mac show text only.
- A client added by hand still gets only the MCP entry, without FULI's global instructions, so its task entry depends on the model; the new check makes a miss visible at once.
- On a fresh installation the built-in FLAs introduce themselves the first time they work for you; after an upgrade, FLAs you already had speak only on a handoff.
- **On a Mac, after every update of FULI the folder permission the system stored no longer matches the new version**; the root cause is that the Mac build has no stable signing identity yet.
- The other limits are those of 0.27.15.

## 数据格式 / Data format

新增一个本地存储 `agent-introductions.sqlite`（记下哪些 FLA 已经认识、每个项目上一位负责人），第一次用到时自动创建，不用确认。其余没有变化，可以直接退回 0.27.15。

One new local store, `agent-introductions.sqlite` (which FLAs you have met and each project's last lead), created on first use with nothing to confirm. Nothing else changes; going back to 0.27.15 works as is.
