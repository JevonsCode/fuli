# FULI 0.12.5

- 会话不再自动建项目、自动招人：没有归属的会话交给固定助理接待，Jefa 在收尾时分诊，同一话题累计 3 个会话自动成为正式项目。
- 项目必须有简介；Agent 必须有职业，Bole 按职业招聘，组长只负责拆活、派活和收口。
- 新增项目间取记忆权重（有关系 / 常往来 / 密切），项目关系图和项目页可直接看到；权重不授予权限。
- 圆桌可以按项目找到对方组长，完成限定请求后把结果交回原组长。
- 任务入口大幅缩小（约 −66%），共享规则改为按需读取；新增 Token 门禁，入口或工具说明变大会被测试拦下。
- Windows 已安装版本可以用 Update-Fuli 预览并升级，保留数据和旧版本，失败自动回退。
