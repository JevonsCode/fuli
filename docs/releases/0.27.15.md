# FULI 0.27.15

0.27.15 发在 `latest` 渠道。托盘菜单能看到谁在干活；Tonborg 没有自己的模型也能用；添加客户端只要发一句话。没有数据格式变化。

0.27.15 is on the `latest` channel. The tray menu shows who is at work; Tonborg works without a model of its own; adding a client takes one message. No data format change.

## 更新内容 / What's new

这一版大半是固定角色重做的后续：Jefa、Astro、Tonborg 都在学着用更少的设置把活干完。托盘也终于不只是一个开关了。

Most of this version follows the redesign of the fixed roles: Jefa, Astro and Tonborg each get the work done with less to set up. And the tray is no longer just a switch.

## 改了什么

- **托盘 / 菜单栏菜单能看到工作**：「打开 FULI」下面列出近 24 小时干过活的助手（正在干的排前面，最多 5 个）和还在讨论的圆桌（最多 3 个），点一下打开对应页面。名字太长或带怪字符会被整理成一行；图服务没响应时只少助手那一块。
- **Tonborg 没有自己的模型也能用**：打开「交给 Tonborg 确认」后，由你当时用的 AI 会话替它确认，也包括在另一个助手验证通过后验收自己的任务。**这个开关只能你本人打开**（在控制台点，或在对话里亲口说），助手不能替你开；给 Tonborg 配了模型（哪怕停用着），会话就只给建议。
- **Jefa 一次说清所有项目的进展**：问「我所有项目进展怎么样」，她一次读完自己管的项目（最多 20 个），先说卡住的和等你验收的。临时会话项目不算在内。
- **Astro 按话题找回以前的对话**：还没归到项目的话题，能直接列出它的那几次对话。
- **每个客户端都有自己的记录开关**：「设置 › 记录」里的开关和客户端列表对得上了。原来的「Claude Desktop」开关改叫「Claude」，它也管 claude.ai / Cowork 的远程连接器；打开「其他客户端」不会顺带打开你关着的 OpenCode、Antigravity、DeepSeek Harness。
- **添加客户端只要发一句话**：把弹窗里那段话原样发给要接入的客户端，它找到自己的配置文件后打开填好的添加窗口，你核对一下点「添加并接入」。接入结果显示在它的卡片上。
- **每个客户端卡片列出 FULI 装了什么**：MCP、自动进入与收尾、Skills 这些部件各自装好了没有、要不要更新；在控制台点「?」能看到每样是干什么的。只有 MCP 的客户端会说明它不会自动进入与收尾。README 里也有一张表说清每样的用处。
- **「让 AI 来做」的提示不用再填空**：九段提示都改成完整的请求，AI 先读当前状态告诉你，只问它不知道的。
- 弹窗里的下拉菜单不再藏到弹窗后面。

## In English

### New

- **The tray / menu bar menu shows the work.** Under 打开 FULI: the assistants that worked in the last 24 hours (the ones at work first, up to 5) and the roundtables still talking (up to 3); a click opens its page. Long or odd names are tidied to one line; if the graph service does not answer, only the assistants part is missing.
- **Tonborg works without a model of its own.** With 「交给 Tonborg 确认」 on, your current AI session confirms for it, including accepting its own task after another assistant's check passed. **Only you can turn that switch on** (in the console, or in your own words in a conversation); an assistant cannot turn it on for you. Once Tonborg has a model configured (even disabled), the session only suggests.
- **Jefa tells you where every project stands in one read.** Ask "how are all my projects doing": she reads the projects she manages (up to 20), stuck and waiting-for-you first. Temporary session projects are left out.
- **Astro finds a topic's earlier conversations.** A topic not yet in a project lists its conversations directly.
- **One capture switch per client.** The switches under Settings › 记录 match the client list. The former "Claude Desktop" switch is named "Claude": it also covers the claude.ai / Cowork remote connector. Turning 「其他客户端」 on no longer turns on OpenCode, Antigravity or DeepSeek Harness if you had them off.
- **Adding a client takes one message.** Send the text in the dialog as it is to the client you add; it finds its own configuration file and opens the add window filled in. Check it and choose 添加并接入. How the connection went shows on its tile.
- **Each client tile lists what FULI put in it.** MCP, auto start and close, Skills and the rest, each with whether it is installed or needs an update; the console's 「?」 explains each one. A client with MCP alone says it does not start and close tasks by itself. The README has a table of what each part gives.

### Fixed

- **「让 AI 来做」 prompts need nothing filled in.** Nine prompts are now whole requests: the AI reads where things stand, tells you, and asks only what it cannot know.
- A list inside a dialog no longer opens behind it.

## 已知限制 / Known limits

- **Mac 上每次更新 FULI 后，系统已存的文件夹许可就对不上新版本了**；根上的原因是 Mac 版还没有稳定的签名身份，这一版没有解决。
- 托盘菜单只在 Windows 上和自动化测试里看过，Mac 的菜单栏还没真机看过。
- Tonborg 由会话代为确认是你选的取舍：会话工作时读到的网页、文件和别人的文字可能影响它的判断，它的批准会被照用。随时可以关掉开关，确认过的都能在「待决策」里撤回。
- 助手通过工具改记录设置时，「其他客户端」还按旧规则一并管 OpenCode、Antigravity、DeepSeek Harness（控制台里已经不会）。
- 其余限制同 0.27.14。

- **On a Mac, after every update of FULI the folder permission the system stored no longer matches the new version**; the root cause is that the Mac build has no stable signing identity yet, not solved in this version.
- The tray menu was seen on Windows and in automated tests only; the Mac menu bar has not been looked at on a real Mac.
- Tonborg confirmed by the session is a trade-off you chose: pages, files and other people's text the session reads may sway it, and its approval is applied. Turn the switch off any time; what it confirmed can be undone in 待决策.
- When an assistant changes capture settings through a tool, 「其他客户端」 still governs OpenCode, Antigravity and DeepSeek Harness by the old rule (the console no longer does).
- The other limits are those of 0.27.14.
