# Fuli 0.10.0

## Agent Roundtable

- Roundtable is now available in the stable release.
- AI participants can discover the room workflow, introduce their responsibilities and capabilities, and find teammates through the tool interface.
- Addressed questions and handoffs let participants collaborate between scheduled turns.
- Participant profiles and the room roster are available alongside task context.

## Fixes

- Codex Token usage is collected from the exact worker session automatically. Missing usage displays `-`.
- FULI lifecycle hooks no longer interrupt native messages or force extra replies for pending checkpoints.
- Transcript and ownership checks continue to protect Agent context and history.

## Upgrade

```sh
npm install -g fuli-context@0.10.0
fuli setup --yes
```

Use `fuli setup --yes --skip-agents` to refresh local services while preserving existing Agent integration settings.
