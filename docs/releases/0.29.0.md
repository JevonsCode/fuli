# FULI 0.29.0

## 0.29.0-beta.1

0.29.0-beta.1 发在 `beta` 渠道。新增「运行机」：另一台电脑上的 Agent 客户端都用这台电脑的 FULI。新增两份本地存储（`runner/host.sqlite`、`runner/runner.sqlite`），已有数据不变。

0.29.0-beta.1 is on the `beta` channel. New: runners, another computer whose Agent clients use this computer's FULI. Two new local stores (`runner/host.sqlite`, `runner/runner.sqlite`); existing data is unchanged.

### 改了什么

- **运行机（Beta）**：在主机上运行 `fuli runner invite`，把打印出的一行在另一台电脑上运行（`fuli runner join …`，10 分钟内有效，只能用一次）。两台电脑互相固定对方的证书（双向 TLS 1.3），运行机上的 Codex、Cursor 和其他 MCP 客户端随即按 `fuli setup` 的方式接好，它们的 FULI 工具都由主机回答。知识、习惯、FLA 和记忆只存在主机上。
- **目录不同也认得项目**：运行机把所在目录的仓库信息（来源地址，不带任何凭据）告诉主机，主机按本机同样的规则认项目、登记新仓库，不读运行机的硬盘。
- **主机暂时连不上**：任务进入用这个目录上次的偏好（标明是离线结果），`checkpoint_task_knowledge` 先排队，其他只读工具给上次的结果，别的操作明确说需要主机。连上后按顺序补交，主机记住每一条，重复送达只算一次。`fuli runner status` 查看，`fuli runner sync` 立即补交。
- **地址变了也找得回来**：主机跟着自己的局域网地址变化监听，并用 mDNS 公布证书指纹；运行机先试上次的地址，再按指纹找。
- **管理**：主机上 `fuli runner list` 列出运行机和最后在哪里见到，`fuli runner revoke` 立即收回访问。邀请运行机只能由你本人在主机上做。

### 这一版的限制

- 两台电脑要能直接连通（同一网络或一根线），不经过任何中继。
- 运行机上不跑生命周期 hook，客户端靠 FULI 的 MCP 工具自己进入任务。

## In English

### New

- **Runners (Beta).** On the host run `fuli runner invite`, then run the printed line on the other computer (`fuli runner join …`, valid once, for 10 minutes). The two computers pin each other's certificates (mutual TLS 1.3); the runner's Codex, Cursor and other MCP clients are set up as `fuli setup` would, and their FULI tools are answered by the host. Knowledge, preferences, FLAs and memory stay on the host only.
- **Projects match whatever the folder is called.** A runner tells the host its folder's repository facts (the origin address, never a credential); the host matches and registers projects by its own rules without reading the runner's disk.
- **While the host is away.** Task entry returns the folder's last preferences, marked offline; `checkpoint_task_knowledge` queues; other read-only tools return their last answer; anything else says it needs the host. The queue is delivered in order once the host answers; the host remembers every entry, so one delivered twice counts once. `fuli runner status` shows it, `fuli runner sync` delivers now.
- **Found again after an address change.** The host follows its LAN addresses and announces its certificate fingerprint over mDNS; a runner tries the last address, then looks the fingerprint up.
- **Managing runners.** `fuli runner list` on the host shows each runner and where it was last seen; `fuli runner revoke` ends its access at once. Only you can invite a runner, on the host.

### Limits of this beta

- Both computers must reach each other directly (one network or a cable); nothing is relayed.
- Lifecycle hooks do not run on a runner; its clients enter tasks through FULI's MCP tools.
