# FULI 0.27.10

0.27.10 发在 `latest` 渠道。只加一件事：你请另一台电脑做的活，可以自己撤回。没有数据格式变化。

0.27.10 is on the `latest` channel. It adds one thing: work you asked another computer to do can be taken back by you. No data format change.

## 更新内容 / What's new

你让另一台电脑帮忙做了件事，做完又觉得不用了。以前只能走过去，在那台电脑上点「丢弃」。现在在这边说一句「撤回」就行，那边的副本和分支会一起收走。

它只收你自己发的、你自己看得到的那件。被安全检查扣下的结果撤不了，那份得由那台电脑的主人亲眼看过；「留下」也仍然只有主人本人能点。

You asked another computer to do something, and once it was done you no longer wanted it. Until now you had to walk over and click Discard there. Now you say "take it back" here, and the copy and the branch there are cleared away.

It only clears what you sent and what you can see. A result that a safety check held back cannot be taken back: the owner of that computer has to look at it. Keeping a result is still only the owner's to click.

## 改了什么

- **发起方可以撤回自己的活**：助手用 `visit_shared_lead` 的 `request_withdraw`（带请求号）撤回。只有发起的那台电脑、只有项目负责人的任务能撤。
- **能撤的**：还没开始做的（在计划、等主人拍板、已批准还没轮到），以及你已经看得到的现成结果（对方现在仍把你的电脑设成「完全信任」）。撤回后那件活记为「已取消」，原因写「对方撤回了」，副本和分支删除。
- **不能撤的**：正在做的（中途叫停会绕过做完后的安全检查，等它做完再撤）、被安全检查扣下的结果、你还看不到的结果、已经留下 / 丢弃 / 结束的。这些仍由那台电脑的主人处理。
- **防空转**：「完全信任」的电脑撤回的活，24 小时内仍算进「合计最多 10 件」那条线。

## In English

### Added

- **The requester can take its own request back.** An assistant uses `visit_shared_lead` `request_withdraw` with the request id. Only the computer that made the request, and only a project lead's task.
- **What can be taken back**: a request whose run has not started (being planned, waiting for the owner, approved and queued), and a ready result you were shown (while the other computer still marks yours fully trusted). The request ends cancelled with the reason "taken back by the requester", and its copy and branch are removed.
- **What cannot**: a run in progress (stopping it midway would skip the safety checks its result gets; take it back once it is done), a result a safety check held back, a result you were not shown, and anything already kept, discarded or ended. Those stay with that computer's owner.
- **No spinning**: for a fully trusted computer, requests taken back still count toward the stop of ten for 24 hours.

## 已知限制 / Known limits

- 两台电脑都要是 0.27.10。对方是旧版本时会拒绝这个动作，这边会提示对方需要更新（这一条在一台真的 0.27.9 电脑上试过）。
- **撤回本身还没有在两台真电脑之间跑过**，只有自动测试和两轮独立安全评审。
- 副本或分支删不干净时会记在那件活的历史里，由那台电脑的主人看到。
- 控制台里还没有「撤回」按钮，现在只有助手能替你撤。
- 其余限制同 0.27.9。

- Both computers must run 0.27.10. An older one refuses the action, and this side says it needs updating (this was tried against a real computer on 0.27.9).
- **The withdrawal itself has not run between two real computers yet**; it rests on automated tests and two independent security reviews.
- Anything the removal leaves behind is noted on that request's history for that computer's owner.
- The console has no "take back" button yet; for now an assistant does it for you.
- The other limits are those of 0.27.9.
