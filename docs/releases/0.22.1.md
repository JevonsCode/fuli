# FULI 0.22.1

0.22.1 没有单独发布，这些修复包含在 [0.23.0](0.23.0.md) 里（从 0.23.0-beta.1 起）。 / 0.22.1 was not released on its own; these fixes ship in 0.23.0, starting with 0.23.0-beta.1.

- 已完成的数据迁移提醒最多显示 7 次，可单独关闭。
- 优化终端中可复制内容的显示，修正图服务不可用时的迁移提示。

- Completed migration notices appear up to seven times and can be dismissed individually.
- Improved copyable terminal output and migration messages when the graph service is unavailable.
