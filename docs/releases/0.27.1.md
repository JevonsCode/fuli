# FULI 0.27.1

0.27.1 发在 `latest` 渠道。它修的是 0.27.0 用了一天之后报上来的问题，另外带了三件新东西：让 AI 整理偏好、任何客户端都能加入的 `#FLG` 讨论、同一个局域网里两台电脑的快速配对（默认关闭，Beta）。两个本地数据库会自动升级一次（见「数据格式」）。

0.27.1 is on the `latest` channel. It fixes what a day of using 0.27.0 turned up, and brings three new things: an AI that tidies your preferences, `#FLG` discussions any client can join, and quick pairing of two computers on one LAN (off by default, Beta). Two local stores upgrade themselves once (see Data format).

## 更新内容 / What's new

用了一天 0.27.0，报上来的毛病这版都修了：项目不会再被隔壁项目「认领」，模型连上了就不再挂着五小时前的红字，Tonborg 帮不上忙的时候会直说。顺手加了三样：偏好可以交给 AI 收拾；`#FLG` 讨论里，别的客户端粘一句话就能入席；两台电脑在同一个网里，对一下六位数就能配上。

A day with 0.27.0 produced a list, and this release works through it: a project is no longer claimed by its neighbour, a model that answers stops showing a five-hour-old error, and Tonborg says so when it cannot help. Three additions came along: an AI can tidy your preferences; in a `#FLG` discussion another client joins by pasting one sentence; two computers on one network pair by comparing six digits.

## 新功能

- **让 AI 整理偏好**：「偏好」页工具栏多了一个 AI 按钮，挑一个已接入的客户端，它把重复的、范围不对的、待确认的偏好列出来，每一项你点头才改。永久删除仍然只有你能做。
- **`#FLG` 讨论，任何客户端都能加入**：发起讨论后会得到一句 `#FLG 加入 XXXX`，在任何接了 FULI 的客户端第一行粘贴，那个会话的 FLA 就加入，OpenCode、Cursor 这些 FULI 叫不醒的客户端也行。每条发言记下是哪个 FLA、哪个客户端、哪个模型。发起时可以选短期或长期、最多几轮；只有发起的会话能开下一轮和总结。
- **附近的 FULI 配对（Beta，默认关闭）**：在「设置 › 连接 › 局域网圆桌」打开「让附近的 FULI 看到这台电脑」，同一网络里的另一台会出现在列表里。点「配对」后两台显示同样的 6 位数字，各自确认一次就配好，不用填地址、不用传邀请。确认只能本人在这台电脑上做。配对后或 30 分钟后发现会自己关掉。
- **一步恢复被阻塞的任务**：不是报告方也不是负责人的 FLA 报「阻塞解除了」，现在一次调用就清掉阻塞并记录，受「设置 › AI 权限 › 组织」管。
- **代你收尾任务**：你说了任务完成或取消，FLA 可以带着你的原话替你关掉它，不需要原负责人的身份。只说「好的」不算。

## 改进

- **Tonborg 的开关如实说话**：开着「交给 Tonborg 确认」但有项目没批准发给它的模型时，开关旁写明能处理几个项目，并带去批准的入口；没批准的项目不再每 20 分钟空跑一次。
- **共用的模型连接共享连通状态**：同一个连接上任一角色刚答上来，其他角色上旧的「连不到这个地址」就换成连接正常。卡片写明状态说的是连接还是这个角色自己的任务。
- **任务列表变小**：`list_project_agent_tasks` 只回摘要并能翻页，不再因为太大被截断。
- **搜索更快**：按意思搜索不再把向量整批读回，单次搜索比 0.27.0 快近一半，结果不变。
- **偏好装不下时不再一条都不给**：先给装得下的（硬性规则优先），其余给个数；让 AI 去取其余部分的办法只在确实可用时才提。
- **分界线上下留白**：模型角色详情里，线下面的内容不再贴着线。

## 修复

- 一个项目把别的仓库登记成参考资料后，那个仓库的克隆会被认成这个项目、负责人被悄悄换掉。现在只有项目自己的仓库参与识别；拿不准时让你选，换负责人时说明依据。
- 每个任务结束时把 `pnpm exec`、`pnpm install` 这类命令记成「Project checks」待确认知识，把待决策堆到上千条。
- 普通的任务记录工具里，Agent 能把一条记录写成「人」做的。
- 随 FULI 一起分发的 `@hono/node-server`（升到 2.1.8）和 `hono`（升到 4.13.18）的中危安全公告。

## In English

### New

- **An AI tidies your preferences.** The Preferences toolbar has an AI button: pick a connected client and it lists duplicate, mis-scoped and pending preferences; each change needs your yes. Permanent deletion stays yours.
- **`#FLG` discussions any client can join.** Starting one returns `#FLG 加入 XXXX`; pasted as the first line in any FULI-connected client, it makes that session's FLA a member, including clients FULI cannot wake such as OpenCode and Cursor. Every message records the FLA, client and model. You choose short or long-lived and a round limit when starting; only the starting session opens a round or summarises.
- **Nearby FULI pairing (Beta, off by default).** In Settings › Connections › LAN roundtable, turn on nearby; another install on the network appears in the list. Pairing shows the same 6 digits on both computers and each person confirms once. No address, no invitation text. Confirming is done by the person on that computer only. Nearby turns itself off after a pairing or 30 minutes.
- **Resume a blocked task in one call.** An FLA that is neither the reporter nor the lead reports the block resolved and FULI clears it and records the report, under Settings › AI permissions › Organisation.
- **Close a task on your behalf.** When you say a task is done or cancelled, an FLA can close it with your exact words. A bare "ok" is not enough.

### Improved

- **Tonborg's switch says what is true.** With projects not approved for its model, the switch says how many it can handle and links to where they are approved; unapproved projects are no longer retried every 20 minutes.
- **Roles on one model connection share its connectivity.** A fresh answer by any role replaces an old "cannot reach" on the others. The card says whether a status is about the connection or the role's own task.
- **The task list is small.** `list_project_agent_tasks` returns summaries with paging instead of being cut off.
- **Search is faster.** Search by meaning no longer reads vectors back in bulk; one search takes about half the time of 0.27.0 with the same results.
- **Preferences that do not fit are no longer dropped entirely.** What fits is delivered (hard rules first) and the rest is counted; the read for the rest is named only when it works.
- **Space around dividers** in a model role's details.

### Fixed

- A project that listed another repository as reference material claimed clones of that repository and silently replaced the owner. Only a project's own repositories count now; when unsure FULI asks, and an owner change says why.
- Every finished task kept commands such as `pnpm exec` and `pnpm install` as pending "Project checks" knowledge, filling the review queue.
- An Agent could write a task event as if the person had made it.
- Moderate advisories in `@hono/node-server` (now 2.1.8) and `hono` (now 4.13.18), both shipped with FULI.

## 已知限制 / Known limits

- 附近的 FULI 配对还没有在真实的 macOS 上走通过，系统的防火墙和本地网络权限提示也没见过；它默认关闭。配对尝试有次数限制（10 分钟内每台设备 3 次、合计 5 次，24 小时 10 次），超了要等一会儿，或者本人在这台电脑上清零。
- 还没有真实客户端用口令加入过 `#FLG` 讨论；控制台里看不到一场讨论的状态。Codex 当主持人时它自己的模型记为「未知」。
- 「一步恢复」和「代你收尾」只有自动测试覆盖；控制台里没有关闭任务的按钮；代你收尾后不能撤销。
- 升级后每个模型角色在下一次调用或测试之前显示「还没调用过」。
- 0.27.0 里已经写错归属的记录不会自动改回；已经堆在待决策里的「Project checks」条目不会被清掉。
- 在 Claude Code 里执行过 `/clear` 的会话，让 AI 取其余偏好的那次读取仍会被拒，它会如实告诉你。

- Nearby pairing has not been run on a real macOS machine, and its firewall and local-network prompts have not been seen; it is off by default. Pairing attempts are limited (3 per device and 5 in all per 10 minutes, 10 per 24 hours); past that, wait, or clear the count on that computer yourself.
- No real client has joined a `#FLG` discussion by code yet; the console does not show a discussion's state. A Codex host's own model is recorded as unknown.
- One-call resume and closing on your behalf are covered by automated tests only; the console has no button to close a task; a close cannot be undone.
- After upgrading, each model role reads "not called yet" until its next call or test.
- Records already filed under the wrong project in 0.27.0 are not moved back; "Project checks" items already waiting for review are not removed.
- In a Claude Code session after `/clear`, the read for the remaining preferences is still refused, and the AI says so.

## 数据格式 / Data format

没有新增图谱迁移步骤。两个本地数据库在第一次启动时自动升级：模型用量库（2 → 3，多一列）和圆桌库（7 → 9，讨论的加入记录和发言来源）。升级前会自动备份；升级后退回 0.27.0 需要用那份备份才能打开这两个库。局域网圆桌的设置里多了附近发现的状态和配对尝试的计数。

No graph migration step is added. Two local stores upgrade themselves at first start: the model usage store (2 → 3, one column) and the roundtable store (7 → 9, discussion joins and message attribution). A backup is taken first; going back to 0.27.0 needs that backup to open them. The LAN roundtable settings gain the nearby state and the count of pairing attempts.

## 安装和升级

需要 Node.js >= 24.12（桌面客户端已内置）。

- **Windows**：在控制台「设置 › 系统 › 版本与更新」点「更新到 v0.27.1」一键更新。也可以下载 `FULI-Setup-0.27.1.exe` 双击（先核对同名 `.sha256`），已装过的会直接更新，数据保留。还可以下载 `fuli-windows-tray-0.27.1.zip`（同样核对 `.sha256`），解压后运行 `Update-Fuli.cmd`。
- **macOS（FULI.app，Apple 芯片）**：在「设置 › 系统 › 版本与更新」点「更新到 v0.27.1」一键更新。第一次安装：下载 `fuli-macos-arm64-0.27.1.dmg`（核对同名 `.sha256`），把 FULI 拖进「应用程序」再打开。
- **npm**（虚拟机、云和服务器）：

```sh
fuli stop
npm install --global fuli-context@latest
fuli setup --yes --connected-only
fuli --version
```

更新后请重启已打开的 Claude Code、Codex 等会话，它们才会用上新版本。

Restart open Claude Code, Codex and other client sessions after updating so they load the new version.
