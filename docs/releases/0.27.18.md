# FULI 0.27.18

## 项目怎么选

在 Astro 模型设置里，正式项目保留自己的名称，临时会话项目默认折叠在「临时项目」一行。行尾显示已选数和总数。展开可以逐项调整，也可以搜索某一项，或一次选中、清空整组。

首次配置时，所有可选项目默认勾选。保存后再次打开，会恢复当时的选择，包括全部清空。切换中英文也能找到之前选的项目。「允许发送不属于项目的内容」由自己的开关控制。

展开后，每项都有绑定原项目的短号。有日期或标题会一并显示。FULI 能用原会话记录核实创建它的客户端时，也会显示 Claude Code、Codex 等来源。[项目选择改动](https://github.com/JevonsCode/fuli/pull/1051) · [原会话来源](https://github.com/JevonsCode/fuli/pull/1053)

## 对话进度

Jefa 可以按有权访问的项目查看各条对话的负责人、最近进展和来源。对话小结里的任务结果可以追溯到写下结果的那条检查点。[对话进度改动](https://github.com/JevonsCode/fuli/pull/1046) · [小结来源改动](https://github.com/JevonsCode/fuli/pull/1044)

## Astro 整理和补检索词

Dreaming 现在会显示正在整理哪个项目，结束后列出读了几条会话、发现几条线索、几条已送审。项目还没授权时，可以从详情直接打开授权设置，保存后回到刚才的项目。「补检索词」会显示已写入的条数、还有几条要补，以及失败后如何重试。[Astro 改动](https://github.com/JevonsCode/fuli/pull/1052)

## Windows 更新

更新安装时，新程序暂时无法启动，已连接的 MCP 客户端会继续使用可用的进程，等新程序就绪后再切换。多个已打开的会话可以各自恢复连接。[Windows 连接修复](https://github.com/JevonsCode/fuli/pull/1050)

遇到连接故障，长按「设置」三秒，可在调试页预览并复制本机故障报告。报告含安装版本、客户端连接状态和近期错误，方便贴到问题反馈里。[故障报告改动](https://github.com/JevonsCode/fuli/pull/1049)

## In English

Astro's model settings keep named projects visible and group temporary conversation projects in one collapsed row. The row shows how many are selected. Expand it to change individual projects, search for one, or select or clear the group.

A new configuration starts with all available projects selected. Reopening a saved configuration restores your choices, including an empty selection, in either language. Content outside projects has its own switch.

Each expanded entry has a short ID and any recorded date or title. When a saved session identifies the client that created the project, the entry also shows its name, such as Claude Code or Codex.

Jefa can report the owner, latest progress and source of each conversation in the projects it can access. Task results in conversation summaries link back to the checkpoint that recorded them.

Dreaming shows the project it is working on and reports the sessions read, leads found and items sent for review. You can grant project access in Astro's settings and return to the same details. Retrieval term generation shows how many entries it has written and how many remain, with a retry when a run fails.

During a Windows update, connected MCP clients can keep using the working process until the new installation is ready. Open sessions can reconnect independently.

Hold Settings for three seconds to preview and copy a local issue report with the installed version, client connection status and recent errors.
