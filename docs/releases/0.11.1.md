# Fuli 0.11.1

## Task ownership fixes

- Tasks in ordinary folders now restore the exact conversation's project before selecting an Agent. A conversation without an existing project receives its own private scope and an HR-assigned lead.
- Existing registered projects and explicit project selections keep priority. Session and client boundaries, ambiguous ownership, and Agent access restrictions remain enforced.
- Failed assignment reports an explicit reason instead of a generic unselected label. A failure never invents an owner.

## Project reporting fixes

- Each project requires an accountable lead. HR can fill a missing lead; removing or replacing an active lead requires a handoff.
- Requests for specialists retain the project lead as accountable owner. Actual delegated member work keeps its own isolated identity and reports to that lead.
- Roundtable delegation uses a short-lived Provider capability bound to the receiving session. Replaying a message header cannot restore another Agent's private context, and unredeemed responses are not attributed to the recipient.
- Concurrent team-policy and assignment changes validate the active lead and members under transaction locks.

## Stable FLA employee numbers

- Fuli Agents (FLAs) receive immutable employee numbers within each personal space, starting at `000001`. Numbers expand beyond six digits when necessary and are never reused after archiving.
- Existing identities receive numbers during upgrade. Agent cards, profiles, the directory, search, and messaging expose or accept the same number.

These changes apply to every supported client through shared application and Provider workflows. Personal Agent names, project assignments, conversation bindings, and local preferences remain user data and are not bundled with the package.

## Upgrade

```sh
npm install -g fuli-context@0.11.1
fuli setup --yes
```

Reconnect existing MCP sessions or restart the client to load the updated code. Use `fuli setup --yes --skip-agents` to refresh local services while preserving Agent integration settings.
