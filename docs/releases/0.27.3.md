# FULI 0.27.3

0.27.3 发在 `latest` 渠道。这是一个修复版，修的是 0.27.2 在两台真电脑上配对之后发现的问题：问另一台电脑的助手会直接失败、同一个助手在两台电脑上长得不一样。顺带放进了「来访的助手」的第一步：配对的电脑可以只读地查你共享的项目。一个本地数据库会自动升级一次（见「数据格式」）。

0.27.3 is on the `latest` channel. It is a fix release for what pairing two real computers on 0.27.2 turned up: asking the other computer's assistant failed outright, and one assistant had two different faces. It also carries the first step of the visiting assistant: a paired computer can read, read-only, a project you shared. One local store upgrades itself once (see Data format).

## 更新内容 / What's new

两台电脑配上之后，0.27.2 有点尴尬：问对面的助手，它不理你，也不说为什么；同一个助手在两边还长着两张脸。这版它会换个方式再试（最多三次），实在不行会留下原因；脸也统一了，不在本机的多一圈虚线。另外，配对的电脑现在可以翻翻你共享的项目，只能看，谁来翻过设置里有记录。

Pairing two computers on 0.27.2 was a little awkward: the assistant on the other side ignored a question without saying why, and wore a different face on each computer. It now tries another way (up to three times) and keeps the reason when it still fails; the face is the same on both, with a dashed ring when it lives elsewhere. And a paired computer can now look through a project you shared, read-only, with a record of who looked.

## 新功能

- **来访的助手（只读）**：配对电脑上的助手可以用 `visit_shared_lead` 看你共享的项目是谁负责（`card`），并搜索这个项目自己的、已确认的、普通敏感度的知识（`search`）。它用的是对方自己的客户端和模型，不会唤醒你这边任何东西。看不到：其他项目、个人习惯、待确认或历史内容、私密或受限内容、助手记忆、本机路径。
- **最近被问**：「设置 › 连接 › 局域网圆桌」里列出哪台电脑问过哪个项目、问了几次，被拒绝的也记。每个项目每 10 分钟最多 60 次、一天 600 次。
- **测试阶段：助手可以替你点配对的「确认」**：你打开了「AI 能做什么 › 局域网圆桌」时，你让它配对的那位助手可以代点。它必须报出对方电脑的指纹，对不上就拒绝；确认后会告诉你是哪台电脑、哪 6 位数字。正式上线前这一步会改回只能由你点。

## 改进

- **问另一台电脑的助手，失败了会再试**：先试它最近的会话，再在同一个客户端开新会话，再换共享里允许的另一个客户端，最多三次。
- **失败会留下原因**：结果里多了原因码（找不到客户端、启动出错、需要登录、异常退出、没有给出回答、输出太大、超时、取消）和试了几次。详细的输出摘要只留在被问的那台电脑上，脱敏后保存，不会传给对方。
- **被别的电脑唤醒的助手只能读**：Claude Code 只带读文件的工具，Codex 在只读沙箱里。讨论组里被唤醒的成员也一样。
- **同一个助手，两边同一张脸**：不在本机的助手按它在自己电脑上的样子画，重新摇过的头像也会带过来；头像外多一圈灰色虚线，鼠标停上去写明是哪台电脑。
- **助手页上可以解除任务阻塞**：被阻塞的任务列在那位助手的页面上，带着原因，右边就是解除的按钮。首页换成「今天」之后，这件事一度只能去任务列表做。
- **「怎么用」页的文字不再铺满整行**：正文保持适合阅读的行宽，卡片和可复制的句子仍然跟着页面宽度。
- **配对前多一句提示**：你的电脑是加入对方的那一方时，确认按钮上方会写「对方电脑负责转交消息，也由它决定组里还有哪些电脑。只和你信得过的电脑配对。」

## 修复

- （Windows）更新不是从客户端里发起时，旧版本的客户端窗口会留着，一重启就报一句英文的 "Invalid Windows installation record"。现在它会写「这是旧版本的 FULI。」并给一个「打开新版本」的按钮，之后的更新也会把它关掉重开。只对这一版起的客户端有效。
- 点别的电脑上助手的头像，会跳到一个不存在的页面，还能对它「重新摇头像」。
- Windows 上启动一个不是程序的文件时，唤醒直接抛出系统错误码。
- 对方电脑可以在失败原因里塞任意文字，提问的助手会原样读到。

## In English

### New

- **The visiting assistant (read-only).** An assistant on a paired computer can use `visit_shared_lead` to see who leads a project you shared (`card`) and search that project's own confirmed, normal-sensitivity knowledge (`search`). It runs on the other computer's own client and model and wakes nothing here. Out of reach: other projects, personal habits, pending or historical items, private or restricted items, assistant memory, local paths.
- **Who asked recently.** Settings › Connections › LAN roundtable lists which computer asked about which project and how often, refusals included. Each project answers at most 60 times per 10 minutes and 600 a day.
- **Test phase: an assistant may click the pairing "Confirm" for you.** With "What AI may do › LAN roundtable" on, the assistant you asked to pair may confirm. It must name the other computer's fingerprint, and a mismatch is refused; it tells you which computer and which six digits it confirmed. Before the formal launch this goes back to you alone.

### Improved

- **Asking another computer's assistant retries.** Its latest session, then a new session in the same client, then the share's other client: three tries at most.
- **A failure keeps its reason.** The result has a reason code (client not found, could not start, login required, exited with an error, no answer, output too large, timed out, cancelled) and the number of tries. The redacted output summary stays on the computer that was asked and is never sent to the other.
- **An assistant woken by another computer can only read.** Claude Code has the file-reading tools only; Codex runs in its read-only sandbox. Members woken for a group discussion get the same.
- **One assistant, one face.** An assistant that lives elsewhere is drawn as on its own computer, re-rolled faces included, with a dashed grey ring; hovering names its computer.
- **Clear a blocked task on the assistant's page.** Blocked tasks are listed there with their reason and the clear action on the right. After the home page became Today this could only be done from the task list.
- **The how-to page keeps a reading measure.** Prose no longer runs the full width; cards and phrases to copy still follow the page width.
- **One more line before pairing.** On the computer that joins: "The other computer relays messages and decides who else is in the group. Pair only if you trust it."

### Fixed

- (Windows) After an update that was not started from the client, an old client window stayed open and showed the English line "Invalid Windows installation record" when it restarted. It now says "This window is an older version of FULI." with one button that opens the new version, and later updates close and reopen it. This covers clients from this version on.
- Clicking the face of an assistant on another computer opened a page that does not exist and offered to re-roll it.
- On Windows, starting a file that is not a program made a wake throw a raw system code.
- The other computer could put free text into a failure reason, and the asking assistant read it as it was.

## 已知限制 / Known limits

- 这版的唤醒重试、来访的助手、助手代点确认都还没有在两台真电脑之间走通过，只有自动测试和独立评审。发布后会在真机上重测。
- 被别的电脑唤醒的助手：你在那个客户端里自己接的其他 MCP 服务（比如 Notion）的工具没有被限制，仍按你平时设的允许规则走。只和你信得过的电脑配对。
- 你的电脑是加入方时，组里有哪些电脑由对方电脑说了算；它可以伪造设备把一个共享项目的读取额度用完。撤销配对即可结束。
- 助手代点配对确认时没有人比对两块屏幕上的数字，只核对了对方的指纹。
- 上传的图片头像不会带到另一台电脑，那边显示默认画的脸。
- 旧窗口的提示页还没有在真实安装上走过一遍。
- 对方电脑还是旧版本时，它看到的失败原因是一整串 `wake_failed;detail=…`。

- This release's retry, visiting assistant and assistant-confirmed pairing have not been run between two real computers yet: automated tests and independent reviews only. They are re-tested on real machines after release.
- An assistant woken by another computer: tools of other MCP servers you added to that client (Notion, for example) are not restricted and follow your usual allow rules. Pair only with computers you trust.
- When your computer is the one that joined, the other computer says which devices are in the group; it could invent devices to use up a shared project's read budget. Revoking the pairing ends it.
- When an assistant confirms a pairing, nobody compared the digits on the two screens; only the other computer's fingerprint was checked.
- An uploaded picture is not sent to the other computer, which shows the generated face.
- The old-window page has not been walked through on a real installation yet.
- An other computer still on an older version shows the failure reason as one string, `wake_failed;detail=…`.

## 数据格式 / Data format

没有新增图谱迁移步骤。一个本地数据库在第一次启动时自动升级：圆桌库（9 → 10，多一张表，记录每次唤醒的结果和原因）。升级前会自动备份；升级后退回 0.27.2 需要用那份备份才能打开这个库。第一次有电脑来访时会新建一个来访记录库。

No graph migration step is added. One local store upgrades itself at first start: the roundtable store (9 → 10, one table recording each wake's outcome and reason). A backup is taken first; going back to 0.27.2 needs that backup to open it. A visitor record store is created the first time a computer visits.

## 安装和升级

需要 Node.js >= 24.12（桌面客户端已内置）。

- **Windows**：在控制台「设置 › 系统 › 版本与更新」点「更新到 v0.27.3」一键更新。也可以下载 `FULI-Setup-0.27.3.exe` 双击（先核对同名 `.sha256`），已装过的会直接更新，数据保留。还可以下载 `fuli-windows-tray-0.27.3.zip`（同样核对 `.sha256`），解压后运行 `Update-Fuli.cmd`。
- **macOS（FULI.app，Apple 芯片）**：在「设置 › 系统 › 版本与更新」点「更新到 v0.27.3」一键更新。第一次安装：下载 `fuli-macos-arm64-0.27.3.dmg`（核对同名 `.sha256`），把 FULI 拖进「应用程序」再打开。
- **npm**（虚拟机、云和服务器）：

```sh
fuli stop
npm install --global fuli-context@latest
fuli setup --yes --connected-only
fuli --version
```

更新后请重启已打开的 Claude Code、Codex 等会话，它们才会用上新版本。两台配对的电脑都要更新。

Restart open Claude Code, Codex and other client sessions after updating so they load the new version. Update both paired computers.
