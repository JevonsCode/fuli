模型指南

接一个模型，FULI 多一种能力。

FULI 不接模型也能用。模型是可选的：接上后，FULI 能按意思查找、给项目归类、整理记忆。

可以用 Ollama 在本机跑模型，也可以用在线模型；它能看哪些项目，由你批准。

两种用法

不用模型（默认）

关键词排序，加上你正在对话的 AI。

免费，不用装任何东西。

配小模型

多了按意思搜索，内置 Agent 也能自己判断。

多数用途，小模型就够。

每个模型做什么

语义搜索

把每条知识和每个问题变成向量，按意思找。

够用
支持中文的小型向量模型，0.3B–0.6B。
示例
通过 Ollama：qwen3-embedding:0.6b（639 MB）、embeddinggemma-2:270m（304 MB）。在线向量接口也可以。
实测

合成留出集：40 个问题、58 条知识、取前 3 条。

  • qwen3-embedding:0.6b32/32 找到 · 8 次中误命中 1 次 · 每次查询 16 ms（台式机 CPU）
  • embeddinggemma-2:270m28/32 找到 · 误命中 1 次 · 18 ms
  • 只用关键词排序同一组题 31/32 找到
Token
用本机模型，不花 Token。

Astro 项目归类

建议一段对话属于哪个项目。

够用
能返回 JSON 的小型或中型对话模型。
实测
未实测

Dreaming 记忆整理

读一个项目最近的会话，提议该记住或退役什么；由人确认。

够用
上下文长的强对话模型。
实测

对一个项目的 21 个真实会话完整跑一次：3 次模型调用，共 143,292 Token。

每天的运行只读上次之后的新内容，花得少得多。

Tonborg 判断

知识留下之前，先审一遍。

够用
强对话模型。
实测

本地 qwen3.5:4b 在 48 个留出案例上与标注一致 60.4%，低于 85% 的门槛。

所以我们建议用强的在线模型，或者当前会话。

Jefa 看板

够用
小型对话模型。
实测
未实测

Bole 绩效

模型能看到什么

  • 模型只看到你批准的项目。
  • 用本机的 Ollama 模型，所有内容都留在你的电脑上。
  • 密钥只保存在这台电脑上。

我们怎么测

只用合成数据，只测一个项目，题目也不多。数字是参考，不是承诺。
