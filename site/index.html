让每一次协作，
都产生复利。

Fuli 给你的每个任务安排一位长期 Agent。它记得你的品味与判断，在接入的 AI 客户端之间接续工作，遇到问题还能直接去问别的 Agent。

$ npm install --global fuli-context $ fuli setup

每个任务

散落的经验，
拼成一位负责的 Agent。

在项目目录里直接提需求。Fuli 登记项目、请 AR 安排一位负责人，之后这个项目的任务都由它接手。做完时，回复最后一行写清楚谁负责、谁协助。

跨工具接续

换 AI 工具，
不用换搭档。

同一位 Agent 的职责、工作记忆和最近的对话都留在 Fuli。在另一个客户端 @ 它，它从上次停下的地方继续，不用你重新交代。

圆桌

Agent 之间，
直接对话。

Codex 里的 Agent 可以去问某一段 Claude Code 对话里的 Agent，就像负责人问同事、或者调用子 Agent。Fuli 在对方的客户端里唤醒它、带回回答。不用建群，不用你转述，每段往来都留痕。

偏好

越用越懂你的
品味与判断。

你的品味、个性和取舍原则会沉淀下来，分成全局和项目两层：全局的在每个项目生效，项目的只管这个项目。Agent 推断出的偏好要你确认才算数。

团队

项目经理与 AR，
固定在岗。

每个空间都自带项目经理 Jefa 和 AR Bole。Jefa 拆解目标、维护看板、为任务找人；Bole 招人并留下招募记录。负责人和成员组成项目小组，各自保留自己的记忆。

记忆

记住工作要点，
接着上次继续。

每次任务的结果都会进摘要。对话攒到一定量，较早的消息折叠成要点，最近的保留原文。原始记录始终在本机，需要时再取回。

数据库

一张图，
记住所有关系。

偏好、项目、Agent、对话以及它们之间的关系，都存在你本机的 Neo4j 图数据库里，每次变化都留有历史。Agent 通过 CLI、MCP 或 HTTP 取用，每次只取当前任务需要的那一小部分。

本地优先

知识图谱和对话记录都在你的电脑上，个人偏好不会进入任何共享层。

人说了算

Agent 可以提议、提醒、归纳；确认、修改和删除始终由你决定。

按需取回

不会把全部历史塞给模型，只取与当前任务有关、仍然有效的内容。

三条命令开始

需要 Node.js 24.12+ 与 Docker（macOS / Linux 也可用原生模式）。安装无需模型；向导会为检测到的 Codex、Claude Code、Cursor 自动配置，其他 MCP 客户端可复制配置接入。

  1. npm install --global fuli-context
  2. fuli setup
  3. fuli open打开 http://127.0.0.1:2727

或者一行安装（会先检查 Node.js 版本）：

curl -fsSL https://xn--8ovp9s.xn--m8txu.com/fuli/install.sh | sh irm https://xn--8ovp9s.xn--m8txu.com/fuli/install.ps1 | iexWindows PowerShell

其他客户端：运行 fuli connect，或在设置中复制 MCP 配置。

通用接入提供工具与记忆；自动采集对话、唤醒会话取决于客户端适配。
