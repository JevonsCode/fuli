需要 Node.js 24.12+。setup 会检查运行环境并展示配置计划。

我能在任何地方直接 @Agent 吗？

需要先为该客户端接入 Fuli，并连接同一份可访问的数据。在 Agent 个人页复制接续指令，指定项目与 Agent 身份，即可请求恢复已保存上下文。原生 @ 菜单、可见转录与自动回写能力取决于客户端适配，Fuli 不会凭空获得没有保存的内容。

会把所有历史都发送给模型吗？

不会。默认使用 7 天不活跃窗口管理近期对话，入口只加载有界摘要、相关偏好与记忆；更完整的证据按需取回。归档与确认知识有不同的权威，旧聊天不会自动变成已经确认的事实。

现在可以部署团队共享服务吗？

当前发布的是本地个人版。独立的团队服务端仍在开发中。此网站仅介绍产品，不托管你的图谱、对话或 Agent 执行环境。
