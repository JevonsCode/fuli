A FEW MORE THINGS

开始前，
你可能想知道。

能在不同客户端继续同一个 Agent 的工作吗？＋

先为客户端接入 Fuli，并连接同一份可访问的数据。在 Agent 个人页复制接续指令，指定项目与 Agent 身份，即可请求恢复已保存的上下文。原生 @ 菜单、可见转录与自动回写能力取决于客户端适配。

会把所有聊天都变成长期知识吗？＋

不会。私有对话、工作记忆与确认知识分开管理。任务结束时检查复用价值，只保留值得留下的候选；没有长期价值时可以不保留。未经确认的猜测不会自动成为人的偏好。

本地优先，意味着完全离线吗？＋

个人图谱与管理界面在本机运行。你使用的模型服务、Agent 客户端与外部知识连接器，仍可能需要网络连接。本地优先是数据管理边界，不代表所有外部服务都离线。

现在可以部署独立的团队服务端吗？＋

目前发布的是个人版 fuli-context。独立的团队服务端仍在开发中。个人品味、个性与判断偏好不会进入团队公共层。本网站仅介绍产品，不托管图谱或 Agent 执行环境。
