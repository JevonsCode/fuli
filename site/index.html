常见问题

怎样验证它有用，或参与改进？

按跨客户端验收步骤 记录记忆恢复、项目隔离和纠正结果。卡住时可提交安装或验收表单； 贡献指南 也列出了文档、测试和首次使用体验的小改进入口。

“长期 Agent”会一直在后台运行吗？

长期保留的是 Agent 的身份、职责与工作脉络。Fuli 在任务需要时组织上下文、协调分工， 具体执行依赖可用且获授权的 AI 客户端或执行器；保存一位 Agent 不等于启动后台任务。

任何客户端都能直接 @Agent 吗？

需要先接入 Fuli，并连接同一份可访问的数据。使用 Agent 的名字或个人页接续指令；是否有原生 @ 菜单、能采集多少对话，由具体客户端与适配器决定。

7 天之后，记忆会被删除吗？

7 天是默认的不活跃归档窗口，可以配置。更早的工作脉络使用紧凑归档恢复，相关原始记录可按需读取；归档和删除是不同的操作。

它会把每一句话都当成我的偏好吗？

不会。私有对话记录与可信的复用知识分开管理。Agent 推断出的偏好保留来源、适用范围与待确认状态，由你决定是否采纳。
