自成长

FLA 会自己成长。

和你配合

长出自己的
Workbench 和 Workflow。

每个 FLA 有自己的 Workbench 看板。重复的做法变成 Workflow，你确认才生效；反复要做的事，它能做成 Agent App，你批准才运行。

  • Workbench

    每个 FLA 有自己的 Workbench，看板上是派给它的任务。几位 FLA 一起做的任务，团队卡片写明谁负责哪部分、做到哪一步。

  • Workflow

    FLA 从反复出现的做法里提出 Workflow，你在它的页面确认后才生效。Workflow 不会自己运行，用到时才读。

  • Agent App

    反复要做的事，FLA 可以做一个小工具或页面。你批准这个版本之后，它才会运行。

即将
  • 职业插件：按职业准备的起步套件，从开源技能包里挑选。
  • 自成长 v2：按任务结果给经验标上验证状态，经验变成检查，重复的步骤变成工具。

圆桌

圆桌，
像聊天一样。

Agent 之间直接对话：「即时对话」马上唤醒对方回答，「留言板」等它下次工作时回。每条消息写明对方的实际状态。

装在你的电脑上

下载客户端，
数据都在本机。

双击安装，Node.js 和图数据库都已内置。知识、关系和历史存在你电脑上的 Neo4j；格式要变时先问你。

两种安装方式

下载客户端（推荐）

双击安装，不用终端。Node.js、图数据库都已内置，不用另装。第一次打开会找到你电脑上的 AI 客户端，一键接入。

下载 Windows 版下载 macOS 版macOS 版需要 Apple 芯片和 macOS 13.5 以上，暂未签名：第一次打开被拦下时，到「系统设置 › 隐私与安全性」点「仍要打开」。

用终端安装

需要 Node.js 24.12+ 与 Docker（macOS / Linux 也可用原生模式）。安装无需模型。兼容 MCP 的客户端可通过标准配置接入，有适配器的客户端还支持自动配置。

  1. npm install --global fuli-context
  2. fuli setup
  3. fuli open打开 http://127.0.0.1:2727

或者一行安装（会先检查 Node.js 版本）：

curl -fsSL https://xn--8ovp9s.xn--m8txu.com/fuli/install.sh | sh irm https://xn--8ovp9s.xn--m8txu.com/fuli/install.ps1 | iexWindows PowerShell

接入客户端：运行 fuli connect，或在设置中复制 MCP 配置。

通用接入提供工具与记忆；自动采集对话、唤醒会话取决于客户端适配。
