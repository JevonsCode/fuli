怎么测的

一个合成项目、一个模型（Claude Haiku 5.5），全是合成数据。FULI 能省多少，取决于有多少会话要用到你以前说过的事。

完整方法
  • 项目：合成的通知转发服务 Tidewater，9 个先后发生的任务，每个任务一个全新会话。
  • 客户端：Claude Code 2.1.301 无头模式。模型：claude-haiku-5-5。日期：2026-11-07。
  • 每个会话开始前，仓库重建成同一状态；两组都关掉 CLAUDE.md 和自动记忆，跨会话的记忆只有 FULI。FULI 每遍从空项目开始。
  • 每组每个会话跑 8 遍，共 144 次。token = 未缓存输入、缓存读取、缓存写入和输出之和；图里是中位数，表里带区间。
  • 做成 = 隐藏检查全过，包括项目自己的测试。每个做成任务的 token = 一组全部 token ÷ 做成次数。
  • s8 没做成的 2 次只差密钥请求头一项。不开 FULI 时 Agent 在无头模式里不能反问；真实使用里，你得把那件事再说一遍。
  • 学到的：s1 你定下的重试策略，在 s2–s6 的入口里都送到，2 遍共 10 次。
  • 召回：另一个合成项目，40 个中英文提问，32 个各有一条该找到的知识，8 个什么都不该找到。只跑 FULI 的任务入口，不调模型。
  • Tonborg：冻结的合成留出集 54 条，走生产审核路径，temperature 0，每个模型 3 轮；5 条注入样本 3 轮共 15 次。日期：2026-11-06。
