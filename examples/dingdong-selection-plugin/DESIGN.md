# 划词工作台视觉规范

## 方向与边界

- 概念：**optical proofing desk / reading proofreading loupe**。它是一张冷色工作台上的暖色校对纸，把阅读、选区、权限和结果放在同一张桌面上；不展开成通用聊天面板。
- 设计种子：`1f2fb29d`。视觉语汇是冷灰绿工作台、米白纸张、钴蓝批注、酸黄校对标记、深绿检查侧栏和精确的细线几何。
- 体验原则：读者留在原地；每个外部能力显式、可解释、按命令授权；无服务时诚实地呈现缺少配置，而不是编造翻译或解释。
- 设计挑战记录：外部 `roll` 服务在本轮不可用，因此当前方向没有外部 challenger 或 quality board 结果。这只是设计过程元数据，不是产品运行状态；界面只呈现真实的文本服务配置与错误状态。

## 布局骨架

### 桌面端

1. `body` 是满视口的浅灰绿工作台，内容以 `workbench` 居中，最大宽度 1440px，外边距使用 `clamp(18px, 3vw, 44px)`。
2. 顶部 `masthead` 是三列网格：左侧放放大镜 wordmark，中间放一句短的定位文案，右侧放“文本服务”配置入口。三列垂直居中，列间距 24px，底部间距 24px。
3. 主体 `workspace-grid` 是左右分栏：阅读纸张约占 `1.55fr`，检查轨约占 `.7fr`，最小轨宽 300px。整体圆角 18px、裁切内部溢出，并以大而柔和的阴影与工作台分离。
4. 左侧 `reading-sheet` 是主视觉和主要阅读区域：内容宽度以 68ch 为上限，左右内边距在 30px–124px 间流动，上下内边距在 42px–104px 间流动。标题、导语、正文、引文和选择提示沿同一阅读轴排布。
5. 右侧 `inspection-rail` 是深绿的固定检查面板，使用纵向 flex；底部权限账本通过 `margin-top: auto` 保持在轨道下方，顶部始终优先显示当前选区。
6. 选中文字后，`selection-toolbar` 作为靠近选区的浮动工具条出现。它是三项明确命令：复制、翻译、解释；不引入搜索框、对话流或额外操作。

### 移动端

- 880px 以下：masthead 收为两列并隐藏中间说明；配置面板收为单列；阅读纸张在上、检查轨在下，形成单列工作流。阅读区至少保持约 76vh 高度。
- 580px 以下：工作台内边距 14px，纸张圆角 14px，阅读纸张使用 42px 24px 68px 内边距；检查轨使用 30px 24px 内边距。标题随视口缩放，但不牺牲大字号层级。
- 移动端浮动工具条不遮挡选区：固定在底部，左右各 12px，三按钮等分并居中；隐藏指向选区的菱形尖角。桌面端仍以选区中心为锚点。
- 移动端阅读纸张与检查轨保持强烈的米白/深绿上下分区，不再显示桌面端纸张右侧的竖向分隔线。

- 检查轨基底为 `#22332e`，工具条基底为 `#142520`；轨内主文字为 `#eef4ef`/`#fffef8`，次级标签为 `#c9d8d0`。
- 就绪状态用小型绿色圆点 `#83d69f`，并配轻微绿色阴影；圆点只是状态提示，不能单独承担语义，必须同时有文字。
- 纸张可以有极淡的蓝色装订/基准线和细边界线；这些线用于“校对台”隐喻，不可成为装饰噪声。
- 阴影表达层级而不是边框：主体工作区使用宽阔、低不透明度阴影；结果卡片和工具条使用更紧的深色阴影。圆角统一从 `14px` 级别起，主体可用 18px。

## 字体、层级与内容密度

- 字体栈：`ui-sans-serif, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`。不依赖外部字体，中文应使用系统可用的无衬线字体。
- 主标题是纸张的最大视觉锚点：`clamp(2.75rem, 6vw, 5.8rem)`，字重约 760，字距 `-.04em`，行高 `.96`，最大宽度约 12ch。移动端可降至 `clamp(2.65rem, 14vw, 4.4rem)`，仍保持紧凑多行节奏。
- 导语使用深钴蓝、约 620 字重、1.2–1.55rem、1.55 行高；它是“注意力靠近”的批注，不是第二个标题。
- 正文与引文约 1.02–1.18rem，行高 1.88，最大宽度 68ch；正文段落之间用约 `1.45em` 外间距。
- 引文是酸黄色校对块，约 24px 30px 内边距，字重约 730；四角细线标记强化放大镜/校对仪器感。移动端可缩小为 22px 内边距并以负 8px 外边距轻微越出正文轴。
- 侧栏标题约 1.45–2rem；选区预览约 1.1–1.42rem、620 字重、1.55 行高。标签、权限名、状态说明保持 0.72–0.82rem，避免与选区内容争夺层级。
- 文案短、直接、以操作为中心。保留“划词工作台”“校对记录”等主标题；不要再叠加 HOW、教学式眉题或解释段落。

## 间距、对齐与组件约束

- 主内容遵循“纸张阅读轴 + 侧栏账本轴”两套对齐：纸张内的标题、段落和引文沿阅读轴；侧栏标题、选区、权限行沿左边界对齐。
- 纸张 meta 在顶部横向两端对齐，标签使用 0.76rem、720 字重；其下方保留约 38–78px 的呼吸空间，给主标题建立开场。
- 检查轨顶部标题与就绪状态同排，状态不换行；当前选区模块上方保留约 44–84px，底部以细线与权限账本分隔。
- 权限账本每行上下约 10px，顶部细线分隔；左列说明“读取选区/写入剪贴板/发送文本/持久保存”，右列展示范围或状态。不要隐藏“持久保存：从不”这一信任信息。
- 配置面板是纸张明亮卡片，最大宽度 980px，右对齐，内边距 16px 18px，控件高度 42px，输入与选择器圆角 8px。帮助文字位于控件下方并跨剩余列。
- 组件之间优先使用空白和细线建立结构，不用厚重描边或多色渐变。

## 交互与状态

- 初始态：阅读区可聚焦；检查轨显示“插件已就绪”、当前选区“尚未选择文字”、状态提示“在左侧选中文字开始”。工具条和结果卡片隐藏。
- 选区态：用户用鼠标或键盘选择阅读区文本后，在选区附近出现工具条；同步更新侧栏选区预览。预览必须可换行、可断词，不能因长选区撑破布局。
- 复制态：仅在用户点击后申请/写入浏览器剪贴板；完成后更新可读状态。复制不发送到远端。
- 翻译/解释态：只有用户明确点击且已配置文本服务后才发送所选内容。执行中对应按钮可禁用并显示等待光标，避免重复请求；结果卡片出现时使用 `aria-live="polite"` 的语义状态。
- 配置态：点击“文本服务”展开/收起配置区，按钮用 `aria-expanded` 与 `aria-controls` 保持同步；默认不连接服务，地址不保存。只允许 HTTPS 或本机回环 HTTP 的约束必须保持在帮助文案中。
- 未配置态：翻译/解释不可偷偷回退到本地猜测；显示可理解的 `TEXT_SERVICE_NOT_CONFIGURED` 语义（界面文案可本地化为“文本服务未配置”），并引导到配置入口。
- 文本服务不可用/降级态：就绪圆点和文字应转为明确的降级/不可用状态，优先使用既有 `--danger` 或 `--muted` 语义，不新增一套视觉语言；保留选区、权限账本和重试/配置上下文。结果区域可显示错误说明，但不显示虚构的翻译、解释、成功数据、延迟或服务健康百分比。
- 所有状态都要能回到阅读：wordmark 链接回 `#reading-sheet`；关闭配置后不清空当前选区；错误不应让阅读纸张跳动或被遮挡。

## 响应式与动效

- 只维护两个结构断点：`880px`（分栏转单列）和 `580px`（紧凑手机工具条与内边距）。其余尺寸通过 `clamp()` 和网格的 `minmax()` 流动适配。
- 选区工具条进入使用短促的 `instrument-in`：从轻微模糊、上移和缩小回到清晰原位；配置/结果面板使用 `unfold` 从上至下展开。动效服务于“仪器靠近注意力”的叙事，不得延迟可用性。
- `prefers-reduced-motion: reduce` 时取消滚动行为、长动画与过渡，保留最终状态和可操作性；不能用动画作为唯一状态提示。

## 可访问性与实现验收

- 保持真实语义结构：`main`、`header`、`article`、`aside`、`section`、`blockquote`、标题层级和 `dl` 权限账本；不要用 div 替代可表达关系的元素。
- 所有功能按钮可用键盘操作，焦点使用 3px 深蓝 `--focus-ring` 内环与 5px 白色外环，在浅色纸张和深色工具条上都保持可见。焦点环不能被裁切、阴影或工具条遮住。
- 阅读区带 `tabindex="0"`，配置入口通过 `aria-expanded`/`aria-controls` 关联面板；表单控件必须有显式 label 与帮助文本关联。
- 浮动工具条使用 `role="toolbar"` 与可读 `aria-label`；图标是 `aria-hidden`，按钮仍必须有中文文本标签。
- 选区预览、结果和状态提示使用 `aria-live`/`role="status"` 的现有语义，状态文本不能只靠颜色或圆点表达。错误信息应明确、可读、可恢复。
- 颜色对比要支持长时间阅读：米白纸张上的墨色、深绿侧栏上的白色文字、钴蓝导语和酸黄焦点分别保持清晰；选中文本时同时设置背景与前景色，不依赖浏览器默认高亮。
- 页面最小宽度为 320px；长 URL、长选区和长结果均应 `overflow-wrap: anywhere`，不产生横向滚动。
- 遵守本地化与隐私边界：不读取凭据、浏览器存储或无关文件；不持久保存选区；服务不可用时诚实暴露状态。

## 防漂移清单

- 是否仍然是一张“阅读纸 + 检查轨”的校对桌，而不是聊天面板？
- 是否保留冷灰绿、米白、钴蓝、酸黄、深绿这组有限色彩和细线几何？
- 是否让选区工具条只暴露复制/翻译/解释三项声明命令？
- 是否在文本服务未配置或不可用时拒绝编造结果，并保留可解释的状态？
- 是否在桌面与手机上都保留主标题、当前选区、权限账本、键盘焦点和 reduced-motion 支持？
